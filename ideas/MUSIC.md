# MUSIC — Банк идей

Идеи, механики и UX, найденные при глубоком исследовании `ItzSudhan/Discord-MusicBot` (v5). Добавляются только после сверки с уже существующим банком.

## ItzSudhan/Discord-MusicBot

- MUSIC-001 — Per-player настройки автоповедения: `autoPause`, `autoLeave`, `autoQueue` и `twentyFourSeven` хранятся непосредственно в состоянии конкретного проигрывателя.
- MUSIC-002 — `Auto Pause`: автоматически ставить воспроизведение на паузу, когда из голосового канала ушли все пользователи.
- MUSIC-003 — `Auto Leave`: автоматически покидать голосовой канал, когда в нём никого не осталось.
- MUSIC-004 — `24/7` режим: не уничтожать player после отключения/окончания очереди и оставаться подключённым к голосовому каналу.
- MUSIC-005 — Отдельная задержка отключения после окончания очереди/простоя; значение `1` может использоваться как практически мгновенное отключение.
- MUSIC-006 — `Auto Queue`: после завершения очереди автоматически искать связанную музыку и продолжать воспроизведение.
- MUSIC-007 — Защита auto-queue от повторов: хранить ограниченную историю последних 100 проигранных track identifier и выбирать ещё не проигранный вариант.
- MUSIC-008 — Автоматический fallback при `queueEnd`: если auto-queue выключен, показать пользователю сообщение об окончании очереди и запустить отдельный таймер disconnect.
- MUSIC-009 — Отмена запланированного disconnect фактом продолжения воспроизведения: перед уничтожением player повторно проверить `playing` и состояние подключения.
- MUSIC-010 — Lifecycle-события audio-node с отдельными логами `connect/reconnect/disconnect/destroy/error`.
- MUSIC-011 — Настраиваемые retry amount/retry delay для восстановления соединения с audio-node.
- MUSIC-012 — Пользовательское сообщение об ошибке конкретного трека: название трека, причина ошибки и дружелюбное пояснение вместо голого stack trace.
- MUSIC-013 — Отдельная обработка `trackStuck` с понятным сообщением пользователю.
- MUSIC-014 — Обработка перемещения player между voice channels: обновлять voice channel, а после перемещения кратко выдерживать задержку перед снятием паузы.
- MUSIC-015 — Если bot принудительно отключили из voice channel, корректно уничтожать player и сообщать об отключении.
- MUSIC-016 — `Now Playing` как единый интерактивный блок: трек + requester + duration + thumbnail + ряд управляющих кнопок.
- MUSIC-017 — Автоматическая замена старого `Now Playing`/pause/resume сообщения новым вместо накопления множества управляющих сообщений.
- MUSIC-018 — Защита от повторного удаления Discord-сообщений через `WeakSet` уже удалённых message objects.
- MUSIC-019 — Контроллер проигрывателя с кнопками `Stop`, `Replay`, `Play/Pause`, `Next`, `Loop`.
- MUSIC-020 — Для controller-действий обязательная проверка: пользователь находится в voice channel.
- MUSIC-021 — Для controller-действий дополнительная проверка: пользователь находится именно в том же voice channel, что и бот.
- MUSIC-022 — `Stop` одновременно очищает очередь, останавливает player и отключает `autoQueue`.
- MUSIC-023 — `Replay` возвращает предыдущий трек, предварительно помещая текущий трек обратно в очередь; при отсутствии валидного previous track действие блокируется.
- MUSIC-024 — Циклический Loop-controller с тремя состояниями: повтор текущего трека → повтор очереди → выключено.
- MUSIC-025 — Кнопочный controller после изменения состояния перерисовывается, чтобы интерфейс сразу отражал актуальное состояние player.
- MUSIC-026 — Ошибки controller/action показываются ephemeral-сообщением и, где это уместно, автоматически удаляются через несколько секунд.
- MUSIC-027 — Унифицированный `SlashCommand`-wrapper поверх `SlashCommandBuilder` с отдельным callback `setRun()`.
- MUSIC-028 — Автоматическая загрузка команд из каталогов `slash` и `context` без ручного списка импортов.
- MUSIC-029 — Help строится динамически из реально загруженных команд; команды с описанием `null` исключаются из пользовательского списка.
- MUSIC-030 — Пагинация Help через Discord buttons с настраиваемым количеством команд на страницу и отключением кнопки на первой/последней странице.
- MUSIC-031 — Help показывает версию приложения и короткий Git commit hash текущей сборки для диагностики.
- MUSIC-032 — Help содержит быстрые ссылки на support server, issues, source и invite.
- MUSIC-033 — Autocomplete для `play` одновременно поддерживает прямые URL и поиск по названию; URL распознаются regex-проверками для YouTube, Spotify, Deezer, SoundCloud и Apple Music.
- MUSIC-034 — Autocomplete возвращает до 25 результатов поиска и отдаёт URL результата как значение выбора.
- MUSIC-035 — `clean` удаляет именно сообщения бота, а не произвольные сообщения канала; для старых сообщений используется отдельное удаление после bulk-delete.
- MUSIC-036 — `clean` имеет пользовательский лимит количества сообщений с диапазоном и безопасным верхним пределом 100.
- MUSIC-037 — Общие `Embed()` и `ErrorEmbed()` helper'ы для унификации визуального ответа команд.
- MUSIC-038 — Конфигурация audio-модуля централизованно задаёт default volume, deafening, presence, embed color, disconnect policy, auto-features и node параметры.
- MUSIC-039 — Managed audio-node допускает несколько независимых node-конфигураций с identifier, host, port, password, retry policy и SSL-флагом.
- MUSIC-040 — Debug-режим явно включает вывод необработанных `unhandledRejection`/`uncaughtException`, а обычный режим подавляет их, чтобы бот не засорял вывод.
- MUSIC-041 — Для Replit отдельно обрабатывается Discord Gateway 429: процесс перезапускается при обнаружении соответствующей ошибки подключения.
- MUSIC-042 — Счётчики `commandsRan` и `songsPlayed` ведутся непосредственно на клиенте для runtime-статистики.
