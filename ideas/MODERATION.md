# Модерация

Все найденные механики записываются без предварительного отбора.

## Cog-Creators/Red-DiscordBot

### MOD-037 — Ролевой mute вместо permission-based mute
- Mute может работать через специально назначенную mute-role вместо channel permission overwrites.
- Режим выбирается настройкой.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-038 — Канальный mute
- Пользователя можно замьютить только в конкретном канале, не ограничивая весь сервер.
- Для разных каналов состояние хранится независимо.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-039 — Автоматический unmute по времени
- Серверные и канальные mute могут иметь время окончания.
- Фоновый обработчик автоматически снимает ограничение после истечения срока.
- Для нескольких канальных mute одного пользователя обработка группируется.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-040 — Отдельный notification channel для проблем mute
- Если автоматический unmute не удался, бот может сообщить об ошибке в специально настроенный notification channel.
- Если канал недоступен, ошибка не ломает весь фоновый обработчик.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-041 — DM-уведомления о mute/unmute
- Mute/unmute может сопровождаться DM пользователю.
- Отдельно можно показывать модератора и причину.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-042 — Ограничение mute Administrator
- Пользователь с Administrator не может быть замьючен обычной mute-операцией.
- Это отдельная проверка до изменения ролей/permissions.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-043 — Graceful ожидание готовности moderation cog
- Команды mute могут ждать завершения асинхронной инициализации cog вместо работы с частично загруженным состоянием.
- При ошибке инициализации команда сообщает об этом и не выполняет действие в неконсистентном состоянии.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО
