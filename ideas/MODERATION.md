## Cog-Creators/Red-DiscordBot

### MOD-015 — Продвинутая очистка сообщений по условиям
- Источник: Cog-Creators/Red-DiscordBot
- Команда cleanup поддерживает несколько способов выборки: последние сообщения, сообщения конкретного пользователя, содержащие заданный текст, диапазон между двумя сообщениями, всё до/после указанного сообщения.
- Можно использовать reply вместо ручного ID сообщения как границу диапазона.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-016 — Очистка сообщений самого бота
- Источник: Cog-Creators/Red-DiscordBot
- Отдельная cleanup bot удаляет сообщения самого бота и команды.
- Распознаются обычные команды, алиасы и custom commands, если соответствующие модули загружены.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-017 — Очистка собственных сообщений с фильтром текста
- Источник: Cog-Creators/Red-DiscordBot
- Команда cleanup self удаляет только сообщения бота.
- Можно дополнительно задать текстовый pattern и удалить только сообщения, содержащие его.
- Для очистки используется обычное массовое удаление, если бот имеет право manage_messages, иначе применяется медленное удаление собственных сообщений.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-018 — Удаление дубликатов сообщений
- Источник: Cog-Creators/Red-DiscordBot
- Отдельная команда duplicates (также alias spam) ищет повторяющиеся сообщения среди последних X сообщений.
- Оставляется первая копия, последующие дубликаты удаляются.
- Сравнение учитывает автора, текст, embeds, stickers и reference сообщения; сложные сообщения с attachments/components/poll/activity исключаются из проверки.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### MOD-019 — Защита массового удаления подтверждением
- Источник: Cog-Creators/Red-DiscordBot
- При удалении более 100 сообщений бот запрашивает подтверждение.
- Подтверждение можно автоматически пропустить через assume-yes контекст.
- Сам prompt и ответ пользователя удаляются после положительного подтверждения, а при отказе выводится отмена.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

- Источник: Cog-Creators/Red-DiscordBot

- Уведомление автоматически удаляется через несколько секунд.
- Настройка включается/выключается отдельно на сервере.
