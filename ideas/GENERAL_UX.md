# General / Small UX Mechanics

## GENERAL-001 — Stopwatch как toggle-команда
Одна и та же команда запускает персональный секундомер, а повторный вызов останавливает его и показывает длительность. Состояние хранится отдельно для каждого пользователя.

## GENERAL-002 — Flip пользователя
Coin-flip команда может принимать пользователя: вместо монетки бот делает шуточную перевёрнутую строку/визуальный эффект над его display name.

## GENERAL-003 — Специальная реакция на попытку flip самого бота
Если пользователь пытается «перевернуть» самого бота, команда меняет адресата на автора и выдаёт отдельную шутливую реакцию.

## GENERAL-004 — Интенсивность интерактивной команды
Простая social-команда может принимать числовой уровень интенсивности и выбирать разные варианты визуального ответа в зависимости от диапазона.

## GENERAL-005 — Humanized numeric limits
Большие числа и лимиты команд форматируются в человекочитаемом виде вместо сырого integer.

## GENERAL-006 — Команда с опциональным detailed-режимом
Одна информационная команда может иметь компактный режим по умолчанию и расширенный режим по флагу, не создавая отдельную команду.

## GENERAL-007 — Server info как диагностический снимок
Расширенный server-info может показывать не только базовые поля, но и распределение участников по humans/bots/status/mobile/streaming, каналы по типам, verification level, features, shard и срок присутствия самого бота на сервере.

## GENERAL-008 — Relative timestamps в информации
Вместо статической даты информационные embed'ы могут одновременно показывать абсолютное время Discord и относительное «сколько времени назад».

## GENERAL-009 — Специальные значки server features
Server-info может визуально различать verified/partnered серверы через feature flags.
