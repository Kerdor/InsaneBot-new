# Help / Command Discovery UX

## HELP-001 — Полностью заменяемый help formatter
Help должен быть отдельным форматтером/слоем, который можно заменить целиком или расширить частично, не переписывая command system.

## HELP-002 — Настройки help как отдельный объект
Все параметры help собирать в единый объект настроек: лимит символов страницы, лимит страниц без меню, тип меню, hidden-команды, aliases, проверка доступности команд, поведение неизвестной подкоманды, задержка удаления, timeout реакций, tagline.

## HELP-003 — Несколько способов навигации help
Поддерживать отключённый режим, реакции, кнопки, кнопки + select menu и только select menu.

## HELP-004 — Help показывает только реально доступные команды
Опционально фильтровать список команд через permission/checks текущего пользователя, чтобы пользователь не видел команды, которыми он не может воспользоваться.

## HELP-005 — Отдельный режим прямого запроса недоступной команды
При прямом запросе можно отдельно разрешить показать существующую, но сейчас недоступную команду; это отличается от фильтрации общего списка.

## HELP-006 — Настраиваемый tagline с placeholder префикса
Текст-подсказка help можно менять, а `[p]` автоматически заменять на актуальный префикс.

## HELP-007 — Автоматическое построение полной сигнатуры
Для вложенной command group help строит полную цепочку родителей + имя команды + signature.

## HELP-008 — Умное отображение aliases
Показывать aliases команды, сортировать короткие первыми, ограничивать общий объём и при переполнении писать количество дополнительных aliases вместо огромного сообщения.

## HELP-009 — Пагинация длинных списков подкоманд
Список subcommands разбивать на страницы с продолжением заголовка, а не обрезать его целиком.

## HELP-010 — Контекстные ответы help в embed или code-block
Формат автоматически зависит от того, запросил ли контекст embeds; один и тот же help имеет полноценное текстовое представление без embeds.

## HELP-011 — Удаление help-сообщения по таймеру
Для help можно задать delete delay; `0` означает отключено.

## HELP-012 — Отдельный timeout меню
Timeout взаимодействия с реакциями/кнопками меню настраивается отдельно от обычного delete delay.

## HELP-013 — Checkmark-подтверждение в DM
При отправке help в DM можно дополнительно использовать реакцию/галочку как UX-сигнал завершения взаимодействия.

## HELP-014 — Кастомный formatter как расширяемый API
Третьесторонний модуль может получить стандартные HelpSettings и реализовать собственный `send_help`, сохраняя совместимость с command discovery.

## HELP-015 — Разные ответы для неизвестной команды и неизвестной подкоманды
Help различает ситуацию «такой команды нет» и «родитель существует, но такой subcommand нет», что позволяет давать более точную подсказку.
