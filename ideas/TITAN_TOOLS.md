# TitanBot — Tools

Источник: `codebymitch/TitanBot`

## Countdown

- TTOOL-006 — Нулевая длительность отклоняется.
- TTOOL-007 — У таймера есть необязательный пользовательский заголовок.
- TTOOL-008 — Для таймера используется дефолтный заголовок.
- TTOOL-009 — Таймер публикуется как отдельное публичное сообщение в канале.
- TTOOL-010 — Управление таймером вынесено в кнопки сообщения.
- TTOOL-011 — Есть Pause/Resume одной кнопкой.
- TTOOL-012 — При паузе сохраняется оставшееся время.
- TTOOL-013 — При Resume конечное время пересчитывается от текущего момента.
- TTOOL-014 — Есть отдельная кнопка Cancel.
- TTOOL-015 — После Cancel управляющие кнопки удаляются.
- TTOOL-016 — После завершения таймера управляющие кнопки удаляются.
- TTOOL-017 — Завершение явно меняет заголовок на Finished.
- TTOOL-018 — Завершение сопровождается текстом Time's up.
- TTOOL-019 — Отмена явно отображается в embed.
- TTOOL-020 — У каждого таймера уникальный ID на базе channel ID и timestamp.
- TTOOL-021 — Активные таймеры хранятся в отдельном runtime Map.
- TTOOL-022 — Состояние таймера содержит message, endTime, remainingTime и isPaused.
- TTOOL-023 — Состояние хранит lastUpdate для контроля частоты редактирования.
- TTOOL-024 — Состояние хранит ссылку на interval для управляемой остановки.
- TTOOL-025 — Таймер проверяется чаще, чем редактируется сообщение.
- TTOOL-026 — Сообщение обновляется примерно раз в секунду.
- TTOOL-027 — При каждом обновлении отображается округлённое вверх оставшееся время.
- TTOOL-028 — Формат времени адаптивный: часы добавляются только при необходимости.
- TTOOL-029 — Время форматируется с ведущими нулями.
- TTOOL-030 — Повторный запуск очищает предыдущий interval состояния.
- TTOOL-031 — Очистка таймера централизована через cleanup-функцию.
- TTOOL-032 — Cleanup удаляет таймер из runtime Map.
- TTOOL-033 — Кнопки таймера доступны только пользователям с Manage Messages.
- TTOOL-034 — Управление несуществующим/истёкшим таймером возвращает понятную ошибку.
- TTOOL-035 — Ошибка редактирования countdown-сообщения логируется без немедленного падения цикла.
- TTOOL-036 — Непредвиденная ошибка обновления очищает runtime-состояние таймера.
- TTOOL-037 — Ошибки button handler изолированы от основного процесса.
- TTOOL-038 — Истёкший countdown не оставляет активный interval.
- TTOOL-039 — Кнопка Pause при паузе меняется на Resume.
- TTOOL-040 — После завершения таймер перестаёт быть интерактивным.

- TTOOL-058 — Base58 сохраняет чувствительность к регистру.
- TTOOL-059 — Base62 сохраняет чувствительность к регистру.
- TTOOL-060 — Разбор больших чисел использует BigInt.

- TTOOL-062 — Ноль имеет специальное форматирование при выводе.
- TTOOL-063 — Base64 преобразуется через байтовое представление.
- TTOOL-064 — Поддерживается обратное преобразование BigInt → Base64.
- TTOOL-065 — Неверные символы отклоняются до вычисления результата.
- TTOOL-066 — Ошибка валидации показывает допустимый алфавит.

- TTOOL-068 — Результат показывает исходное значение, целевое значение и Decimal.
- TTOOL-069 — При multi-output результат оформляется единым embed.

- TTOOL-071 — Ошибки парсинга и конвертации логируются отдельно.
