# MUSIC COMMANDS — Банк идей

Дополнительные механики `ItzSudhan/Discord-MusicBot` (v5), извлечённые из `commands/slash/`. Не дублируют базовые MUSIC-001–MUSIC-042.

- MUSIC-C001 — `search` показывает до 10 результатов через Select Menu, позволяя выбрать конкретный трек перед добавлением в очередь.
- MUSIC-C002 — Поисковый Select Menu имеет TTL 30 секунд и после таймаута заменяется сообщением о том, что трек не выбран.
- MUSIC-C003 — После выбора результата `search` повторно резолвит выбранный URI через player перед добавлением в очередь.
- MUSIC-C004 — `play` различает одиночный трек, поисковый результат и playlist load и показывает разные подтверждения для каждого типа.
- MUSIC-C005 — При добавлении одиночного трека показывается его позиция в очереди, если он не является единственным элементом.
- MUSIC-C006 — При добавлении playlist показываются число поставленных песен и суммарная длительность playlist.
- MUSIC-C007 — Временный ответ `Searching...` и финальный ответ `play` автоматически удаляются через TTL, чтобы служебные сообщения не засоряли канал.
- MUSIC-C008 — Для Stage Channel `play` после подключения проверяет `suppress` и пытается снять suppression либо отправить request-to-speak.
- MUSIC-C009 — `seek` принимает составное человекочитаемое время (`1h 30m`, `80m`, `53s`) и суммирует его компоненты.
- MUSIC-C010 — `seek` явно сообщает, была ли новая позиция rewind или обычным seek, сравнивая её с текущей позицией.
- MUSIC-C011 — `volume` без аргумента превращается в просмотр текущей громкости, а не выдаёт ошибку об отсутствии параметра.
- MUSIC-C012 — `save` отправляет текущий трек пользователю в DM вместе со ссылкой, длительностью, автором и исходным сервером.
- MUSIC-C013 — После `save` пользователю показывается инструкция проверить DM и открыть личные сообщения, если они закрыты.
- MUSIC-C014 — `queue` имеет отдельный компактный UX для короткой очереди и расширенный пагинируемый UX для длинной.
- MUSIC-C015 — Пагинация очереди использует страницы по 10 треков.
- MUSIC-C016 — Переход по страницам очереди циклический: после последней страницы идёт первая, перед первой — последняя.
- MUSIC-C017 — Интерактивная очередь имеет одновременно общий TTL collector и idle timeout.
- MUSIC-C018 — Кнопки очереди разрешены только пользователю, вызвавшему команду; остальные получают ephemeral-предупреждение.
- MUSIC-C019 — `remove` удаляет трек по номеру позиции очереди.
- MUSIC-C020 — `move` переносит выбранный трек из одной позиции очереди в другую.
- MUSIC-C021 — `skipto` пропускает промежуточные треки до указанной позиции и отдельно обрабатывает переход на позицию 1.
- MUSIC-C022 — `previous` защищён от возврата к треку, который уже является current или первым queued track.
- MUSIC-C023 — `replay` реализован как seek текущего трека в позицию 0, без добавления новой записи в очередь.
- MUSIC-C024 — `stop` в режиме 24/7 очищает очередь и останавливает player, но сохраняет voice connection; без 24/7 уничтожает player.
- MUSIC-C025 — `summon` создаёт player только при отсутствии существующего и может перенести существующий player в новый voice channel.
- MUSIC-C026 — Фильтры доступны через единый preset enum: Nightcore, BassBoost, Vaporwave, Pop, Soft, Treblebass, Eight Dimension, Karaoke, Vibrato, Tremolo.
- MUSIC-C027 — В preset-интерфейсе фильтров есть отдельная операция `Reset`, полностью сбрасывающая EQ.
- MUSIC-C028 — `ping` показывает одновременно WebSocket/API latency и задержку ответа самого бота.
- MUSIC-C029 — Для latency используются визуальные статусы по порогам: нормальный, предупреждение, высокий.
- MUSIC-C030 — `stats` объединяет Discord, Lavalink, Node.js и системные показатели в одном embed.
- MUSIC-C031 — Lavalink stats показывают uptime, RAM и количество playing players относительно общего количества players.
- MUSIC-C032 — Админские команды проверяют единый конфигурационный `adminId` перед выполнением.
- MUSIC-C033 — `reload` сбрасывает Node.js require cache и повторно импортирует slash/context commands без полного рестарта процесса.
- MUSIC-C034 — `reload` сообщает итоговое количество успешно загруженных команд.
- MUSIC-C035 — Loader/reloader валидирует наличие ожидаемой структуры command-модуля и пишет имя конкретного проблемного файла.
- MUSIC-C036 — `invite` генерирует OAuth URL из `clientId`, permissions и scopes конфигурации и выдаёт его link-кнопкой.
- MUSIC-C037 — `lyrics` работает как с явно переданной песней, так и с текущим playing track.
- MUSIC-C038 — Перед поиском lyrics название текущего трека очищается от шумовых суффиксов (`Official`, `Lyrics`, `Remix`, `Live`, `Cover` и др.).
- MUSIC-C039 — `lyrics` сначала предлагает несколько совпадений через Select Menu, затем показывает текст выбранного результата.
- MUSIC-C040 — Выбор результата lyrics ограничен 30 секундами; отсутствие выбора превращается в явное сообщение о таймауте.
- MUSIC-C041 — Lyrics-ответ содержит кнопки `Tips` и `Source` для дополнительного UX после выбора текста.
- MUSIC-C042 — При запрете публикации lyrics пользователю показывается понятное объяснение ограничения источника вместо пустого ответа.
- MUSIC-C043 — Lyrics длиннее лимита embed автоматически обрезаются с явной пометкой `Truncated`.
- MUSIC-C044 — `search` показывает duration/`LIVE` и author непосредственно в элементах Select Menu.
- MUSIC-C045 — При отсутствии результатов поиска бот отдельно сообщает об отсутствии результатов и предлагает проверить запрос.
- MUSIC-C046 — `seek` отказывает при попытке перейти за пределы длительности текущего трека и объясняет причину.
- MUSIC-C047 — `previous` перед возвратом кладёт текущий трек обратно в начало очереди, сохраняя возможность вернуться вперёд.
- MUSIC-C048 — `play` устанавливает previous track при первом добавленном треке, чтобы история воспроизведения имела начальное состояние.
- MUSIC-C049 — `save` делает персональное сохранение трека через DM вместо публичного ответа в музыкальном канале.
- MUSIC-C050 — Короткая очередь в `queue` может быть представлена одним embed без навигационных кнопок, снижая UI-шум.
- MUSIC-C051 — Длинная очередь сохраняется в одном сообщении и обновляется через button collector вместо создания нового сообщения на каждую страницу.
- MUSIC-C052 — После завершения/таймаута интерактивной очереди collector прекращает принимать дальнейшие кнопки.
- MUSIC-C053 — `stop` отключает `autoQueue`, чтобы после ручной остановки система не возобновила связанную музыку автоматически.
- MUSIC-C054 — `summon` перед перемещением проверяет текущий voice channel player и меняет его только при необходимости.
- MUSIC-C055 — Команды с отсутствующим player используют отдельные пользовательские ошибки вроде `Nothing is playing`, `I'm not in a channel` или `There is no music playing`, а не единый неинформативный ответ.
