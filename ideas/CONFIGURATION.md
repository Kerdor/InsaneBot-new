# CONFIGURATION — Банк идей

Системы гибкой иерархической настройки поведения бота.

## Cog-Creators/Red-DiscordBot

### CONFIG-001 — Иерархия настроек embed-ответов
- Источник: Cog-Creators/Red-DiscordBot
- Для embed-ответов используется цепочка fallback-настроек вместо одного глобального переключателя.
- В сервере приоритет может быть: channel override → server command override → server override → global command override → global default.
- В DM: user override → global command override → global default.
- Отдельно можно задавать значение для конкретной команды и отдельно для всего сервера/пользователя.
- Пустое значение сбрасывает override и возвращает наследование.
- Есть команда просмотра итоговых значений всех уровней, включая конкретную команду.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CONFIG-002 — Scoped configuration с наследованием
- Источник: Cog-Creators/Red-DiscordBot
- Одна настройка может существовать на нескольких уровнях: global, guild, channel, user и command-specific scope.
- Более узкий scope переопределяет общий, а отсутствие значения позволяет использовать fallback.
- Это позволяет не дублировать конфигурацию и точечно менять поведение только там, где это нужно.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CONFIG-003 — Явный reset override вместо toggle-only настроек
- Источник: Cog-Creators/Red-DiscordBot
- Для настроек, наследующих значение сверху, предусмотрена третья операция помимо True/False: очистить локальное значение.
- После clear система снова использует глобальное/родительское значение.
