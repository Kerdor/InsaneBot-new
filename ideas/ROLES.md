# ROLES — Банк идей

Механики самостоятельного управления ролями и администрирования ролей.

## Cog-Creators/Red-DiscordBot

### ROLE-001 — Selfrole как toggle
- Источник: Cog-Creators/Red-DiscordBot
- Пользователь одной командой выдаёт себе разрешённую роль, а повторным вызовом снимает её.
- Отдельные скрытые add/remove-варианты позволяют явно выполнить только одну сторону операции.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### ROLE-002 — Список доступных selfroles
- Источник: Cog-Creators/Red-DiscordBot
- Пользователь может запросить список ролей, которые ему разрешено выдавать себе.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### ROLE-003 — Массовая настройка selfroles
- Источник: Cog-Creators/Red-DiscordBot
- Администратор может добавить или удалить сразу несколько selfroles одной операцией.
- Есть отдельная операция полного очищения списка.
- Перед изменениями проверяется иерархия каждой роли.
- Перед разрушительным clear используется подтверждение yes/no.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### ROLE-004 — Автоочистка невалидных selfroles
- Источник: Cog-Creators/Red-DiscordBot
- При чтении конфигурации selfroles бот обнаруживает роли, которые больше не существуют.
- Невалидные ID автоматически удаляются из конфигурации.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### ROLE-005 — Редактирование цвета роли через hex
- Источник: Cog-Creators/Red-DiscordBot
- Цвет существующей роли можно менять отдельной командой через hex-значение.
- Проверяется иерархия роли относительно пользователя и бота.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### ROLE-006 — Редактирование имени роли
- Источник: Cog-Creators/Red-DiscordBot
- Имя существующей роли можно менять отдельной командой.
- Перед изменением выполняются проверки иерархии пользователя и бота.
