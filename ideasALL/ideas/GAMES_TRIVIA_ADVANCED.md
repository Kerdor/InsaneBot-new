# GAMES — Расширенные Trivia-механики

Специфические механики викторины из Cog-Creators/Red-DiscordBot, не дублирующие общий список игр.

## Cog-Creators/Red-DiscordBot

### TRIVIA-001 — Смешивание нескольких наборов вопросов в одной игре
- Несколько категорий можно указать при запуске одной сессии.
- Вопросы объединяются в единый пул и перемешиваются.
- Настройки первой указанной категории имеют приоритет над остальными.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-002 — Авторские пользовательские наборы Trivia
- Владелец может загружать собственные YAML-наборы вопросов.
- Наборы валидируются по схеме перед сохранением.
- Есть просмотр списка загруженных наборов и удаление набора.
- Загрузка может ожидать attachment следующим сообщением с timeout и поддерживать отмену.
- Ошибки синтаксиса и ошибки схемы показываются раздельно.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-003 — Настройки внутри конкретного набора вопросов
- Сам trivia-list может содержать CONFIG и переопределять серверные настройки.
- Администратор может отдельно запретить спискам изменять настройки сервера.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-004 — Метаданные trivia-list
- Набор может содержать AUTHOR и DESCRIPTION.
- Автор показывается при запуске игры.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-005 — Победа по заданному количеству очков
- Сессия заканчивается сразу, когда любой участник достигает заданного max score.
- Лимит настраивается для каждого сервера.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-006 — Отдельный таймер ответа и таймер бездействия всей игры
- `delay` определяет, сколько секунд даётся на конкретный вопрос.
- `timeout` определяет, сколько можно не получать ответов вообще до остановки всей сессии.
- Таймер бездействия сбрасывается при любой попытке ответа.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-007 — Автоматическая игра бота
- Если никто не отвечает правильно за отведённое время, сам бот может получать +1 очко.
- Это отдельная настройка и не мешает обычному подсчёту игроков.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-008 — Рандомизированные сообщения правильного/неправильного ответа
- Для раскрытия ответа используется случайная фраза из набора.
- При включённых spoilers бот скрывает ответ через Discord spoiler formatting.
- При отключённом reveal answer используются отдельные случайные сообщения перехода к следующему вопросу.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-009 — Гибкое распознавание ответа
- Ответ приводится к нижнему регистру и нормализуются smart quotes.
- Для многословных ответов допускается совпадение фразы внутри сообщения.
- Для однословных ответов достаточно совпадения отдельного слова, а не полного сообщения.
- Сообщения из другого канала и сообщения самого бота игнорируются.
- Для YAML bool-ответов допускаются человекочитаемые варианты True/Yes/On и False/No/Off.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-010 — Экономическая награда победителю только при достаточном числе игроков
- Выплата за Trivia активируется отдельным multiplier.
- Награда выдаётся только если участвовало минимум 3 человека.
- При ничьей награда делится поровну между победителями.
- Размер выплаты рассчитывается от итогового счёта победителя.
- Есть защита от превышения максимального баланса.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-011 — Статистика Trivia по участнику
- Для каждого участника хранятся wins, games и total_score.
- Данные отделены от временных scores конкретной сессии.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-012 — Одновременная сессия ограничена каналом
- В одном канале нельзя запустить вторую Trivia-сессию, пока первая активна.
- При этом другие каналы сервера могут иметь свои независимые сессии.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-013 — Отдельная команда принудительной остановки сессии
- Остановка вызывает завершение текущей игровой задачи.
- Нормальное завершение показывает результаты, а принудительное завершение может отменить task без повторного вывода.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TRIVIA-014 — Самостоятельный lifecycle игровой async-сессии
- Каждая Trivia-сессия работает как отдельная background task.
- Ошибка task перехватывается и превращается в безопасное сообщение.
- Ошибки Discord NotFound/Forbidden корректно завершают сессию.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО
