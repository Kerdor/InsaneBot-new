# Tomato6966 — Batch 9, Part 2

Источник: `Tomato6966/Multipurpose-discord-bot`
Ветка: `new_2025`

## `commands/💪 Setup`

### TOM-117 — Настраиваемый AI-Chat канал
- Администратор назначает конкретный канал, в котором бот отвечает через AI-chat.
- Систему можно отдельно включить и выключить.
- Есть отдельный просмотр текущего канала.
- Выбор канала поддерживает как mention, так и ввод ID.

### TOM-118 — Anti-Caps с процентным порогом и whitelist каналов
- Администратор задаёт максимально допустимый процент CAPS в сообщении (`0–100%`).
- При превышении сообщение не-администратора удаляется; повторные нарушения могут привести к mute.
- Можно добавлять и удалять каналы из whitelist.
- Есть отдельный лимит нарушений до mute.
- Система имеет собственный экран настроек и независимое включение/выключение.

### TOM-119 — Anti-Discord Links с whitelist каналов и серверов
- Отдельная защита от рекламных/пригласительных Discord-ссылок.
- Можно включать/выключать систему.
- Каналы можно исключать через whitelist.
- Можно whitelist-ить конкретные Discord-ссылки/серверы.
- Настраивается порог нарушений до mute.
- Есть экран текущих настроек.

### TOM-120 — Anti-Mention с лимитом упоминаний в сообщении
- Ограничивает количество member/role mentions в одном сообщении.
- Лимит задаётся администратором в диапазоне `1–100`.
- Сообщения нарушителей удаляются; повторные нарушения могут привести к mute.
- Есть whitelist каналов.
- Система отдельно включается/выключается и имеет экран настроек.

### TOM-121 — Автоматические резервные копии сервера по расписанию
- Владелец сервера может включить автоматический backup.
- Backup создаётся раз в `2 дня`.
- Старые автоматические backup'ы автоматически удаляются.
- Setup показывает команды просмотра и загрузки backup'ов.
- Для настройки требуется владелец сервера и `ADMINISTRATOR` у бота.

### TOM-122 — Auto-Delete с отдельной задержкой для каждого канала
- Можно добавить несколько каналов, в которых сообщения автоматически удаляются.
- Для каждого канала задаётся собственная задержка.
- Допустимая задержка: `3–3600 секунд`.
- Каналы можно удалять из настройки и просматривать списком.
- При просмотре показывается канал и фактическая задержка.
- Setup очищает из хранилища несуществующие каналы.

### TOM-123 — Auto-Embed для выбранных каналов
- Можно назначить несколько каналов, в которых сообщения обрабатываются системой автоматических Embed'ов.
- Каналы добавляются/удаляются независимо.
- Есть список всех настроенных каналов.
- При просмотре setup удаляет из конфигурации уже несуществующие каналы.

### TOM-124 — Автоматическая публикация мемов по минутному интервалу
- Администратор назначает канал для автоматических мемов.
- Публикация выполняется раз в `1 минуту`.
- Систему можно включить/выключить.
- Есть просмотр настроенного канала и cooldown.

### TOM-125 — Автоматическая публикация NSFW-контента в NSFW-канал
- Администратор назначает канал для автоматической публикации NSFW-изображений.
- При настройке канал проверяется на наличие NSFW-флага; обычный канал не принимается.
- Публикация выполняется раз в `1 минуту`.
- Систему можно включить/выключить и просматривать настройки.

### TOM-126 — Массовое переключение Auto-Warn правил
- Setup позволяет одним multi-select переключить сразу несколько правил Auto-Warn.
- Доступны Auto-Warn для Anti-Spam, Anti-Mention, Anti-Links, Anti-Discord, Anti-Caps, Blacklist, Ghost Ping Detector и Anti-Self-Bot.
- После операции показывается число включённых и выключенных правил.
- Auto-Warn применяется только если соответствующая защитная система сама включена.

### TOM-127 — Anti-Nuke с модульными защитами и отдельными whitelist
- Комплексная защита от разрушительных действий на сервере.
- Отдельные модули: добавление ботов, kick/ban, создание/удаление ролей, создание/удаление каналов.
- Для каждого модуля можно отдельно включать защиту и задавать whitelist пользователей/ролей.
- Для действий предусмотрены независимые пороги `за день / неделю / месяц / за всё время`.
- Для разных типов наказания можно отдельно включать `remove roles`, `kick` и `ban`.
- Некоторые модули умеют автоматически удалять созданный злоумышленником канал/роль или возвращать удалённую роль.
- Есть общий logger, отображение whitelist-изменений и режим quarantine.
- Настройка доступна только владельцу сервера (плюс специальный owner ID разработчика).
- Есть Suggested Settings и отдельная синхронизация прав quarantine-роли на каналы.
