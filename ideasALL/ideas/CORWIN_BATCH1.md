# CorwinDev/Discord-Bot — Batch 1

Источник: `CorwinDev/Discord-Bot`, branch `main`.

## Автонастройка

### COR-001 — Единая autosetup-команда
- Один интерфейс для быстрого развёртывания разных подсистем сервера.
- Подсистемы создают необходимые каналы/роли и сразу сохраняют их ID.

### COR-002 — Автосоздание инфраструктуры для функций
- Автоматически создавать отдельные каналы для birthdays, chatbot, reviews, suggestions и starboard.

### COR-003 — Автосоздание игровых каналов
- Отдельные каналы для counting, guess-the-number, guess-the-word и word-snake.
- После создания сразу публиковать стартовую инструкцию/первое состояние игры.

### COR-004 — Автосоздание скрытого server-log канала
- Лог-канал создаётся сразу с запретом просмотра для `@everyone`.

### COR-005 — Автонастройка boost/level логов
- Отдельные каналы для бустов и событий уровней.

### COR-006 — Автосоздание welcome/leave инфраструктуры
- Создавать Welcome/Bye каналы и Member-роль одной командой.

### COR-007 — Автосоздание панели тикетов
- После настройки ticket-системы автоматически публиковать кнопку открытия тикета.
- Если ticket-система не настроена — явно сообщать об этом.

### COR-008 — Шаблон названия временного voice
- Автонастройка custom voice сразу задаёт шаблон `{emoji} {channel name}`.

## Automod / Security

### COR-009 — Channel whitelist для антилинков
- AntiLinks/AntiInvite работают глобально, но конкретные каналы можно добавить в whitelist.

### COR-010 — Whitelist + Manage Messages bypass
- Модератор с `ManageMessages` может публиковать ссылки даже в защищённом канале.

### COR-011 — Проверка ссылок при редактировании
- AntiLinks/AntiInvite должны проверять не только новые сообщения, но и изменённые.

### COR-012 — Временное уведомление об удалённой ссылке
- После удаления запрещённого edited-message отправлять предупреждение и автоматически убирать его через несколько секунд.

### COR-013 — Раздельные режимы AntiInvite и AntiLinks
- Приоритетная проверка Discord-инвайтов отдельно от общего URL-фильтра.

### COR-014 — Кэширование настроек security
- Настройки guild security можно читать через короткоживущий cache, уменьшая нагрузку на БД.

### COR-015 — Простой blacklist слов
- Слова хранятся на уровне guild.
- Добавление существующего слова должно давать отдельную ошибку.

### COR-016 — Проверка blacklist по словам
- Нормализовать сообщение в lowercase и разбивать на токены перед проверкой.

### COR-017 — Blacklist для edited messages
- Запрещённое слово удаляется и при обычной отправке, и после редактирования сообщения.

### COR-018 — Локальный антиспам-счётчик
- Для пользователя хранится последнее сообщение, число сообщений и timer очистки.

### COR-019 — Окно антиспама с двумя порогами
- Быстрые сообщения считаются в коротком интервале.
- Более длинная пауза сбрасывает счётчик.

### COR-020 — Автоматическая очистка anti-spam state
- Временные пользовательские данные удаляются через timeout, чтобы Map не рос бесконечно.

## Economy

### COR-021 — Покупка server-role через магазин
- Экономический магазин может продавать Discord-роли.
- После оплаты роль автоматически выдаётся пользователю.

### COR-022 — Магазин через Select Menu
- Покупатель выбирает товар из интерактивного меню вместо текстового ввода.

### COR-023 — Экономические предметы с состоянием
- Помимо денег можно хранить предметы/флаги пользователя.

### COR-024 — Покупаемый инструмент с прочностью
- Fishing Rod — предмет, который имеет отдельное состояние использования.
- После достижения случайного/заданного лимита предмет ломается.

### COR-025 — Fishing как cooldown-механика
- Рыбалка имеет собственный cooldown.
- Результат выбирается из списка добычи.

### COR-026 — Добыча с редкими предметами
- В таблицу результатов обычного действия можно включать редкие/необычные награды наряду с обычными ресурсами.

### COR-027 — Crime как рискованная активность
- Действие имеет cooldown.
- Результат случайно становится успешным или провальным.
- При успехе выдаются деньги, при провале — только сообщение о поимке.

### COR-028 — Несколько тематических вариантов одного действия
- Crime может случайно выбирать конкретный тип преступления для результата.

### COR-029 — Ограничение на ограбление по кошельку
- Rob требует минимальный баланс у инициатора.

### COR-030 — Ограбление конкретного пользователя
- Цель выбирается как Discord user.
- Нельзя грабить ботов.
- Нельзя грабить пользователя без доступных денег.

### COR-031 — Ограничение суммы robbery
- Награда rob случайная, но не может превышать доступную сумму цели.

### COR-032 — Cooldown для PvP-экономических действий
- Rob и Crime используют отдельные timestamps, чтобы ограничивать частоту.

### COR-033 — Многоуровневые ежедневные награды
- Economy предусматривает daily/weekly/monthly/yearly циклы получения награды.

### COR-034 — Разделение wallet и bank
- Наличие `deposit`/`withdraw` позволяет разделять деньги пользователя на доступный кошелёк и банковский баланс.

### COR-035 — Передача денег между пользователями
- Экономика поддерживает прямой `pay` между участниками.

### COR-036 — Подарочная передача
- Отдельная механика `present` для передачи экономической ценности как подарка.

### COR-037 — Leaderboard экономики
- Баланс можно агрегировать в серверную таблицу лидеров.

## Casino / Games

### COR-038 — Blackjack с интерактивным управлением
- Игра ведётся через кнопки `Hit`/`Stand`.
- Состояние игры обновляется в одном сообщении.

### COR-039 — Blackjack с отдельными состояниями игрока и дилера
- Отдельно хранятся карты и score обеих сторон.
- Туз автоматически пересчитывается с 11 на 1 при необходимости.

### COR-040 — Скрытая карта дилера
- Во время партии можно показывать только часть руки дилера.
- Полная рука раскрывается при завершении.

### COR-041 — Dealer stand threshold
- Дилер автоматически добирает карты до минимального score.

### COR-042 — Проигрыш ставки при timeout интерактивной игры
- Если игрок не завершил casino-игру в заданное время, ставка считается проигранной.

### COR-043 — Crash game
- Коэффициент растёт во времени.
- Пользователь может забрать выигрыш до случайного момента crash.

### COR-044 — Live-edit состояния Crash
- Multiplier и потенциальная прибыль обновляются редактированием одного сообщения.

### COR-045 — Disabled controls после завершения Crash
- После cashout/crash кнопка останавливается и становится disabled.

### COR-046 — FastType с измерением времени
- Пользователь должен воспроизвести случайную фразу.
- Результат показывает фактическое время выполнения.

### COR-047 — FastType с командами отмены
- `cancel`/`end` позволяют завершить активную игру вручную.

### COR-048 — Snake прямо в Discord components
- Игровое поле отображается символами в embed.
- Управление идёт кнопками направления.

### COR-049 — Snake с уникальными component IDs
- Для игровой сессии генерируются уникальные custom IDs, чтобы старые кнопки не пересекались с новой игрой.

### COR-050 — Snake с disabled-кнопками как визуальная раскладка
- Пустые/служебные позиции интерфейса можно занимать disabled buttons для сохранения структуры управления.

## Family / Social

### COR-051 — Семейное дерево пользователя
- Family-система хранит партнёра, родителей и детей.

### COR-052 — Marriage proposal через кнопки
- Предложение брака подтверждается/отклоняется самим target-пользователем через buttons.

### COR-053 — Автоматическая отмена предложения по timeout
- Если target не ответил за заданный срок, предложение считается отклонённым.

### COR-054 — Запрет брака внутри family graph
- Нельзя жениться на родителе/ребёнке или другом родственнике.

### COR-055 — Запрет второго брака
- Перед предложением проверяется семейный статус обеих сторон.

### COR-056 — Семейные операции как отдельный social graph
- Adopt/disown/divorce/family/propose/delete образуют самостоятельную социальную подсистему.

## Custom commands

### COR-057 — Server custom slash commands
- Администратор может создать настоящую guild slash-команду из интерфейса бота.

### COR-058 — Custom command с выбором типа ответа
- При создании можно выбрать `Normal`, `Embed` или `DM`.

### COR-059 — Custom command DM response
- Пользовательская команда может отвечать инициатору в личные сообщения.

### COR-060 — Удаление custom command из Discord API
- Удаление пользовательской команды удаляет и сохранённую запись, и зарегистрированную guild command.

## Setup / configuration

### COR-061 — Настройка сообщений через отдельные config-команды
- Welcome, leave, level и ticket messages вынесены в отдельные команды конфигурации.

### COR-062 — Настройка цвета бота
- Guild может задавать собственный цвет для bot embeds.

### COR-063 — Настройка имени custom voice
- Шаблон временного voice channel можно конфигурировать отдельно от механики создания каналов.

### COR-064 — Verification как настраиваемая подсистема
- Verification имеет отдельную конфигурацию и setup-команду.

## Guild / Statistics

### COR-065 — Расширенная серверная статистика
- Отдельные счётчики для members, bots, roles, text/voice/stage/news channels, emojis, boosts и tier.

### COR-066 — Раздельные static/animated emoji counters
- Статистика эмодзи разделяется по типу.

### COR-067 — Server stats как отдельные обновляемые сущности
- Каждая статистика может обновляться своим event-handler, а не пересчитываться только при ручном запросе.

### COR-068 — Invite tracking с отдельной моделью
- Приглашения и их авторы сохраняются для последующей статистики/reward-системы.

## Tickets

### COR-069 — Проверка `isTicket`
- Любую ticket-команду можно защитить общей проверкой, что текущий channel действительно является тикетом.

### COR-070 — Получение ticket metadata по channel ID
- Ticket channel хранит отдельную запись с guild + channel ID.

### COR-071 — HTML transcript
- История тикета экспортируется в HTML-шаблон.

### COR-072 — Безопасная очистка transcript HTML
- Пользовательский текст проходит sanitization перед вставкой в HTML.

### COR-073 — Transcript с поддержкой reply references
- В HTML сохраняется визуальная ссылка на процитированное сообщение.
- Если оригинал удалён — transcript явно это показывает.

### COR-074 — Transcript с мультимедиа
- Изображения отображаются как изображения.
- Видео и аудио получают собственные HTML controls.
- Остальные вложения отображаются как скачиваемые файлы.

### COR-075 — Transcript с embed reconstruction
- Embed переносится в HTML с author/title/description/fields/thumbnail/image/footer.

### COR-076 — Lazy loading transcript media
- Медиа в большом transcript используют lazy loading.

## Архитектурные наблюдения

### COR-077 — Feature-specific database models
- Для каждой подсистемы используются отдельные Mongo/Mongoose модели вместо одной гигантской guild-документации.

### COR-078 — Interaction layer отделён от реализации команды
- `interactions/Command/*.js` описывают slash-command структуру, а `commands/<name>/<subcommand>.js` реализуют конкретную операцию.

### COR-079 — Dynamic subcommand dispatch
- Handler может выбирать файл реализации по `commandName + subcommand`, вместо огромного switch.

### COR-080 — Общие client helpers
- Повторяющиеся операции вроде embeds, success/error replies, money, setup и ticket logic вынесены в client methods.
