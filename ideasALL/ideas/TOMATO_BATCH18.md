## `botconfig/`

### TOM-243 — Twitch Live Logger с несколькими отслеживаемыми каналами
- Для сервера можно хранить несколько Twitch-каналов в одной конфигурации.
- Для каждого отслеживаемого канала сохраняются имя, Discord user ID и собственный текст уведомления.
- Бот периодически проверяет статус каналов через Twitch API.
- При переходе в live отправляется Embed с названием стрима, игрой, зрителями, ссылкой, thumbnail и preview.
- Последний `stream ID` сохраняется, поэтому один и тот же запуск не уведомляется повторно.

### TOM-244 — Twitch Live → автоматическая роль + временный ping
- При выходе отслеживаемого стримера в live бот автоматически выдаёт указанную роль связанному Discord-пользователю.
- После окончания стрима роль снимается.
- Для уведомления можно отдельно настроить роль, которую бот временно упоминает в сообщении; само ping-сообщение затем удаляется.

### TOM-245 — Автоматическое обновление Twitch OAuth-токена
- Twitch access token автоматически получают через Client Credentials flow.
- Токен обновляется периодически (раз в час) и сохраняется в конфигурации.
- Основная проверка стримов использует актуальный токен без ручного обновления.

## `social_log/`

### TOM-246 — Twitter Feed с фильтрацией ответов и ретвитов
- Бот периодически проверяет настроенные Twitter-аккаунты.
- Ответы на другие твиты исключаются из уведомлений.
- Ретвиты можно отдельно разрешить/запретить для каждого аккаунта.
- Для каждого аккаунта задаются Discord-канал и шаблон сообщения с `{Twittername}` и `{url}`.
- ID последнего опубликованного твита хранится для защиты от повторной отправки.

### TOM-247 — YouTube Feed с несколькими каналами и историей отправленных видео
- На одном сервере можно отслеживать несколько YouTube-каналов.
- Для каждого канала хранится последнее видео и список уже отправленных видео.
- Уведомление поддерживает шаблонные placeholders: URL, автор, название и дата публикации.
- Проверяется валидность YouTube-канала перед отправкой.

## Исключено
- `social_log/tiktok.js` проверен, но текущая функция проверки сразу завершает работу сообщением о том, что TikTok Logger отключён; рабочей механикой в текущей ветке не считается.
- `twitterfeed2.js` содержит полностью закомментированную альтернативную реализацию и не считается рабочей системой.
- `botconfig` JSON-файлы с эмодзи, базовыми цветами Embed, радиостанциями и статическими значениями не добавлены как самостоятельные механики.
