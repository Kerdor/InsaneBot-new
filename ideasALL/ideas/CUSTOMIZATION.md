## Cog-Creators/Red-DiscordBot — дополнительные варианты

### CUST-026 — Серверные и глобальные алиасы команд
- Источник: Cog-Creators/Red-DiscordBot
- Категория: Кастомизация / Команды
- Описание: Пользователь может создавать собственные короткие имена для существующих команд; отдельно поддерживаются глобальные алиасы.
- Механики / детали: Алиас перенаправляет вызов на существующую команду, может хранить аргументы и дополняться аргументами из нового вызова. Есть add/edit/delete/show/help/list, проверка конфликтов с настоящими командами и ограничение имён.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CUST-027 — Алиас как сохранённая команда с аргументами
- Источник: Cog-Creators/Red-DiscordBot
- Категория: Кастомизация / Команды
- Описание: Алиас может быть не просто синонимом, а сохранённым вызовом команды с заранее заданными аргументами.
- Механики / детали: При вызове алиаса дополнительные аргументы пользователя добавляются к сохранённым; используется форматирование позиционных аргументов. Это позволяет делать собственные shortcuts вроде заранее настроенных команд.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CUST-028 — Поиск custom commands с fuzzy matching
- Источник: Cog-Creators/Red-DiscordBot
- Категория: Кастомизация / UX
- Описание: Поиск пользовательских команд по неточному совпадению.
- Механики / детали: Используется fuzzy-поиск, возвращающий близкие имена команд вместо требования точного совпадения.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CUST-029 — Randomized custom command
- Источник: Cog-Creators/Red-DiscordBot
- Категория: Кастомизация / Развлечения
- Описание: Custom command может иметь несколько вариантов ответа и выбирать случайный.
- Механики / детали: Создание интерактивное: пользователь добавляет несколько ответов, пока не введёт команду выхода. Все варианты должны принимать одинаковые аргументы.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CUST-030 — Raw-просмотр custom command
- Источник: Cog-Creators/Red-DiscordBot
- Категория: Кастомизация / UX
- Описание: Получение исходного markdown-ответа custom command для копирования.
- Механики / детали: Отдельная команда показывает экранированный raw-текст; для нескольких вариантов ответа используется постраничный просмотр.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CUST-031 — Метаданные custom command
- Источник: Cog-Creators/Red-DiscordBot
- Категория: Кастомизация / Аудит
- Описание: Для custom command сохраняются автор, редакторы, дата создания и дата изменения.
- Механики / детали: При редактировании пользователь добавляется в список editors, а время изменения обновляется. Это позволяет видеть историю владения/изменений без полноценного audit log.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### CUST-032 — Индивидуальные cooldowns custom commands
- Источник: Cog-Creators/Red-DiscordBot
- Категория: Кастомизация / Ограничения
- Описание: Для каждой custom command можно задавать отдельные cooldown-настройки.
- Механики / детали: Cooldown хранится вместе с конкретной командой и может изменяться при редактировании; неактивные значения удаляются.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО
