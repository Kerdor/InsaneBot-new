# Tomato6966 — Batch 9, Part 4

Источник: `Tomato6966/Multipurpose-discord-bot`
Ветка: `new_2025`
Раздел: `commands/💪 Setup`

### TOM-172 — Раздельная настройка Welcome в канал и DM
- Welcome System поддерживает отдельное публичное welcome-сообщение в выбранном канале и отдельное Direct Welcome Message в личные сообщения.
- Канальная и DM-ветки управляются независимо.
- Канальный welcome можно отключить, не затрагивая остальные части системы.

### TOM-173 — Две независимые Welcome-панели для разных каналов
- Помимо основного welcome channel система позволяет настроить второе обычное сообщение в другом канале.
- Второй вариант работает без Embed и задаётся отдельно от основного welcome.

### TOM-174 — Welcome Roles при входе
- При вступлении участнику можно автоматически выдавать настроенные welcome roles.
- Setup предоставляет отдельные операции добавления, удаления и просмотра ролей.
- Это отдельная часть Welcome System, не завязанная на текст сообщения.

### TOM-175 — Welcome CAPTCHA как security layer
- Welcome setup содержит отдельный CAPTCHA Security System.
- CAPTCHA можно включать/выключать из общего welcome dashboard.
- Система предназначена для проверки нового участника перед полноценным допуском.

### TOM-176 — Welcome/Leave изображения с несколькими режимами
- Для welcome и leave сообщений можно отключить изображение, включить автоматически генерируемое изображение с данными пользователя либо использовать Custom Image.
- Для auto-image можно отдельно задавать/сбрасывать background.
- Это позволяет выбирать между динамической генерацией и статическим пользовательским фоном.

### TOM-177 — Дополнительные элементы на Welcome/Leave изображении
- Генерируемое изображение может отдельно показывать/скрывать colored frame, user tag/discriminator, server member count и server name.
- Каждый элемент переключается независимо.
- Настройки применяются к соответствующему welcome/leave image renderer.

### TOM-178 — Invite Information в Welcome/Leave
- Welcome и Leave сообщения имеют отдельный toggle для показа информации о пригласившем пользователе.
- Информация об invite tracker не является обязательной частью основного сообщения и может быть отключена.

### TOM-179 — Тестирование текущего Welcome Message из setup
- Welcome setup содержит отдельное действие `Test Welcome`.
- Администратор может проверить текущую конфигурацию welcome, не дожидаясь нового join event.

### TOM-180 — Настраиваемый Leave Message System с теми же image/DM возможностями
- Leave setup поддерживает отдельный канал для leave сообщений и отдельные Direct Leave Messages.
- Для channel leave можно отключать сообщение, редактировать текст и управлять image renderer.
- Leave image имеет auto/custom/background и дополнительные visual toggles.

### TOM-181 — Кастомные Welcome/Leave сообщения поверх image renderer
- Текст welcome/leave сообщения редактируется отдельно от изображения.
- Это позволяет менять текстовую часть, не меняя image configuration.

## Проверенные дубли / технические замечания
- `setup-leave.js` и большая часть `setup-welcome.js` используют общую модель image/customization; уникальные части объединены выше, а не размножены по каждому похожему пункту.
- `setup-warn.js` отдельно сохранён как threshold/role reward система; он не сводится к общему Auto-Warn.
