# CorwinDev/Discord-Bot — Batch 3

Источник: `CorwinDev/Discord-Bot`, branch `main`.

## Games / Fun

### COR-126 — Trivia с внешним вопросником
- Вопросы можно получать из внешнего API вместо хранения всего набора вопросов локально.

### COR-127 — Trivia с уровнями сложности
- Игра может запрашивать вопросы конкретной сложности; в источнике используется hard.

### COR-128 — Trivia с четырьмя интерактивными ответами
- Варианты ответа представлены четырьмя кнопками.
- Правильный вариант определяется после перемешивания ответов.

### COR-129 — Уникальные IDs игровой сессии
- Каждая кнопка trivia получает случайный длинный ID, уменьшая риск пересечения с другими активными играми.

### COR-130 — Trivia показывает время ответа
- После правильного ответа игроку показывается фактическое время от старта вопроса до ответа.

### COR-131 — Визуальный разбор результата trivia
- После ответа все кнопки блокируются.
- Правильная кнопка получает Success, выбранная неправильная — Danger, остальные остаются нейтральными.

### COR-132 — Автоматическое завершение trivia
- По истечении таймера игра завершается без ответа пользователя.
- Правильный вариант подсвечивается, а все controls блокируются.

### COR-133 — Would You Rather с общественным процентом выбора
- Вопрос содержит две опции, а после голосования отображаются проценты предыдущих ответов сообщества.

### COR-134 — Персональный голос в Would You Rather
- После выбора кнопка пользователя визуально сохраняется как выбранная, обе кнопки становятся недоступными.

### COR-135 — Will You Press The Button с результатами сообщества
- Дилемма содержит действие и его последствие.
- После выбора отображается статистика Yes/No из внешнего источника.

### COR-136 — Последовательная emoji-анимация в одном сообщении
- Fun-команда может создавать мини-анимацию редактированием одного interaction message через серию таймеров.

### COR-137 — Fun-анимация с финальным состоянием
- Последний кадр может превращаться в отдельное `Mission Completed` состояние вместо отправки множества сообщений.

### COR-138 — ASCII text renderer
- Обычный текст можно преобразовать в крупный ASCII-art прямо в embed.
- Перед генерацией применяется ограничение длины входа.

### COR-139 — Randomized fun-response pools
- Простые rate/roast/fact команды могут выбирать результат из локального массива случайных ответов.

## Giveaways

### COR-140 — Last-chance окно перед завершением giveaway
- Перед окончанием giveaway включается отдельное короткое предупреждение о последнем шансе.

### COR-141 — Pause/unpause giveaway
- Активный giveaway можно поставить на паузу и затем возобновить.
- Состояние паузы имеет собственное сообщение и цвет.

### COR-142 — Drop giveaway
- Отдельный режим giveaway определяет победителя по первому участнику, успевшему нажать/отреагировать.

### COR-143 — Giveaway edit с добавлением времени
- Уже запущенный giveaway можно продлить без пересоздания.

### COR-144 — Giveaway reroll
- Завершённый giveaway можно перерозыграть отдельной операцией.

### COR-145 — Удаление giveaway по message ID
- Управление giveaway выполняется через ID исходного сообщения.
- Перед операцией проверяется принадлежность giveaway текущему guild.

## Moderation

### COR-146 — Moderation case numbering
- Warn получает последовательный case number на уровне guild.
- Case сохраняется вместе с moderator, reason и timestamp.

### COR-147 — Warn history как массив событий
- У пользователя хранится не только количество предупреждений, а полная история отдельных warning entries.

### COR-148 — Unwarn по конкретному case
- Снять можно именно выбранное предупреждение, не очищая всю историю.

### COR-149 — Warning total в просмотре истории
- Команда просмотра warnings показывает общее количество предупреждений и затем отдельные cases.

### COR-150 — События warnAdd/warnRemove
- Изменение warning state может дополнительно эмитить внутреннее событие для логов/других обработчиков.

### COR-151 — Двухуровневая проверка прав модератора
- Для разных moderation-команд можно использовать `checkPerms` и `checkUserPerms` как отдельные уровни permission abstraction.

### COR-152 — Массовая очистка канала с жёстким лимитом
- Clear валидирует диапазон 1–100 до вызова Discord bulk-delete API.

### COR-153 — Global channel lockdown
- Lockdown может одним действием запретить отправку сообщений `@everyone` во всех текстовых каналах сервера.

### COR-154 — Временный ban как отдельная сущность
- Tempban сохраняет guild, user и время истечения в БД, чтобы бан можно было снять автоматически позже.

### COR-155 — DM перед moderation action с fallback
- Перед ban/kick/timeout можно попытаться уведомить пользователя в DM.
- Если DM недоступен, само moderation action всё равно выполняется, а ответ модератору меняется.

## Profile / Social

### COR-156 — Составной пользовательский профиль
- Профиль может объединять Discord-данные, собственные поля, коллекции интересов, badges и внутренние credits в одной карточке.

### COR-157 — Мультизначные поля профиля
- Любимые игры/еда/музыка/фильмы/артисты/актёры/хобби могут храниться как списки, а не как одно значение.

### COR-158 — Защита от повторения элементов профиля
- Перед добавлением hobby/интереса проверяется наличие такого же значения в текущем списке.

### COR-159 — Select Menu для profile enum
- Поля с фиксированным набором вариантов удобнее задавать через String Select Menu вместо свободного текста.

### COR-160 — About Me с отдельным лимитом
- Свободный текст профиля ограничивается Discord-совместимым размером поля и сохраняется отдельно.

### COR-161 — Discord badges + bot badges в одном профиле
- В карточке можно различать системные Discord flags и собственные badges бота.

## Reaction Roles

### COR-162 — Reaction role panel через Select Menu
- Одна панель может содержать список ролей с emoji, label и description.
- Выбор добавляет или снимает соответствующую роль.

### COR-163 — Reaction role panel через Buttons
- Та же категория ролей может публиковаться как набор кнопок вместо select menu.

### COR-164 — Категории reaction roles
- Роли группируются под именованной категорией, а panel строится из сохранённой конфигурации категории.

### COR-165 — Сохранение ID опубликованной панели
- После отправки reaction-role panel её message ID записывается в конфигурацию для последующей обработки/удаления.

## Music

### COR-166 — Music controls требуют общий voice context
- Команды music проверяют, что пользователь находится в voice channel.
- При существующем player дополнительно проверяется совпадение voice channel.

### COR-167 — Поиск музыки с интерактивным выбором
- Если поиск возвращает несколько треков, бот показывает первые варианты как numbered buttons.
- Отдельная кнопка позволяет отменить выбор.

### COR-168 — Автоматическое отключение music selection по timeout
- Если пользователь не выбрал трек за заданный срок, controls блокируются, а player может быть уничтожен при отсутствии текущего трека.

### COR-169 — Playlist как отдельный результат поиска
- Поисковый результат playlist добавляет сразу несколько треков в queue.

### COR-170 — Текущий трек как rich status
- `playing` показывает title, requester, duration, volume, thumbnail и текстовый progress bar.

### COR-171 — Текстовый progress bar музыки
- Позиция трека визуализируется символами и slider-emoji внутри embed.

### COR-172 — Previous track
- Player хранит предыдущий трек и позволяет запустить его отдельной командой.

### COR-173 — Music control row
- Previous/pause/stop/next можно представить одной action row прямо в сообщении текущего трека.

### COR-174 — Queue management
- Queue можно просматривать с индексами и requester для каждого ожидающего трека.
- Отдельные операции позволяют удалить конкретный элемент, очистить очередь или перемешать её.

### COR-175 — Skip-to по позиции queue
- Пользователь может пропустить несколько элементов очереди и сразу перейти к указанной позиции.

### COR-176 — Seek с обновлением progress
- Seek принимает время в секундах и после перемещения показывает новое положение в progress bar.

### COR-177 — Loop текущего трека
- Loop может переключаться между `none` и повтором текущего track.

### COR-178 — Bass boost presets
- Эквалайзер может иметь несколько заранее заданных уровней bass boost вместо произвольного значения gain.

### COR-179 — Lyrics текущего трека по умолчанию
- Если song не указан, lyrics-команда автоматически использует название текущего проигрываемого трека.

### COR-180 — Music volume query/set одним command
- Если volume argument не указан, команда показывает текущую громкость.
- При наличии значения она изменяет volume.

## Tools / Search / Media

### COR-181 — Интерактивный Discord calculator
- Калькулятор полностью управляется Discord buttons.
- Есть AC, backspace, арифметика, скобки, степень и процент.

### COR-182 — Calculator invalid-expression state
- Ошибка вычисления показывается непосредственно в дисплее калькулятора вместо отдельного сообщения.

### COR-183 — Calculator disable mode
- Отдельная кнопка может завершить сессию калькулятора и заблокировать весь control row.

### COR-184 — QR-код как inline image
- Строка превращается в QR-код и показывается непосредственно в embed.

### COR-185 — Генератор пароля с DM delivery
- Сгенерированный пароль отправляется пользователю в DM, а публичный ответ сообщает только о результате.

### COR-186 — Text ↔ binary utilities
- Бот может кодировать текст в последовательность binary bytes и выполнять обратное декодирование.

### COR-187 — Source code paste service
- Длинный код можно отправлять во внешний paste-сервис с указанием языка.
- Пользователю возвращается ссылка вместо огромного сообщения в Discord.

### COR-188 — URL shortener с custom alias
- Команда сокращения ссылки может принимать желаемый short code.
- Ошибку внешнего сервиса можно вернуть пользователю как validation error.

### COR-189 — Emoji enlarger
- Custom Discord emoji можно преобразовать в прямую PNG/GIF ссылку большого размера.

### COR-190 — Emoji stealer с ограничением роли
- Emoji можно импортировать на текущий сервер и при создании сразу ограничить доступ выбранной ролью.

### COR-191 — Weather card
- Weather utility может показывать timezone, temperature, feels-like, humidity и wind в одной карточке.

### COR-192 — Crypto price lookup
- Запрос цены поддерживает coin + quote currency и возвращает текущую цену одной монеты.

### COR-193 — GitHub profile lookup
- Search utility может показывать avatar, name, company, bio, public repositories и дату создания аккаунта.

### COR-194 — npm package lookup
- Package lookup может показывать version, description, keywords, author, downloads и дату последней публикации.

### COR-195 — Steam application lookup
- Game lookup может показывать description, developers, publishers и price вместе с thumbnail.

### COR-196 — Discord.js documentation lookup
- По имени сущности можно получить готовую embed-карточку документации через внешний docs API.

### COR-197 — YouTube search shortcut
- Простой search command может не загружать результаты, а сразу формировать безопасную URL поискового запроса.

### COR-198 — Generated image meme templates
- Image commands могут генерировать meme/template изображения на основе avatar и текста пользователя.

### COR-199 — Multi-user generated images
- Image generation может принимать несколько Discord users и собирать их avatar'ы в один результат, например podium.

### COR-200 — User banner fallback to accent color
- Если у пользователя нет banner, image command может показать доступный accent color вместо пустого результата.

### COR-201 — User-generated image actions
- Набор image commands может использовать avatar target + действие (`bed`, `wanted`, `drake`, `colorify` и т.п.) как отдельные визуальные мини-механики.
