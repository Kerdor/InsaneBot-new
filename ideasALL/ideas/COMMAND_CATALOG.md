# COMMAND CATALOG — сырой каталог команд

Этот файл создан для **максимального сбора команд**, включая самые обычные, вспомогательные, административные и потенциально бесполезные.

Правило: на этапе добычи команда фиксируется даже если кажется очевидной. Повторяющиеся команды из разных источников не удаляются, если у них может отличаться UX, поведение, параметры или ограничения.

## ItzSudhan/Discord-MusicBot

Источник: `ItzSudhan/Discord-MusicBot`, ветка `v5`.

### Slash-команды

- `247` — режим постоянного нахождения в голосовом канале.
- `autoleave` — автоматически покидать голосовой канал, когда он пуст.
- `autopause` — автоматически ставить воспроизведение на паузу, когда канал пуст.
- `autoqueue` — автоматическое добавление следующего контента в очередь.
- `clean` — очистка сообщений/музыкального интерфейса.
- `clear` — очистка очереди.
- `filters` — управление аудиофильтрами.
- `guildleave` — принудительный выход бота с сервера.
- `help` — справка по командам.
- `invite` — ссылка/приглашение для добавления бота.
- `loop` — повтор текущего трека/режим повтора.
- `loopq` — повтор всей очереди.
- `lyrics` — поиск/вывод текста песни.
- `move` — перемещение элемента в очереди.
- `nowplaying` — информация о текущем треке.
- `pause` — пауза.
- `ping` — проверка отклика.
- `play` — запуск воспроизведения.
- `previous` — возврат к предыдущему треку.
- `queue` — просмотр очереди.
- `reload` — перезагрузка/обновление компонента.
- `remove` — удаление элемента из очереди.
- `replay` — повтор текущего трека.
- `resume` — продолжение после паузы.
- `save` — сохранение музыкального состояния/данных.
- `search` — поиск музыки.
- `seek` — переход на позицию внутри трека.
- `shuffle` — перемешивание очереди.
- `skip` — пропуск текущего трека.
- `skipto` — переход к конкретному элементу очереди.
- `stats` — статистика бота.
- `stop` — остановка воспроизведения.
- `summon` — подключение/перемещение бота в голосовой канал.
- `volume` — управление громкостью.

### Context command

- `play` — запуск воспроизведения через context menu.

## Архитектурные находки, которые тоже считаются добычей

- Отдельный класс/обёртка для slash-команды.
- Автоматическая загрузка команд из директории.
- Отдельные event handlers: interactionCreate, messageCreate, messageDelete, raw, ready, voiceStateUpdate.
- Отдельный controller для музыкального интерфейса.
- Отдельные DB helpers и guild DB.
- Отдельный helper получения канала.
- Отдельный helper конфигурации.
- Отдельный helper подключения Lavalink.
- Logger как самостоятельный компонент.
- Dashboard как отдельное приложение.
- Статическая production-сборка dashboard хранится в репозитории.
- Отдельные deploy/destroy сценарии для global и guild команд.
- Docker Compose и отдельная конфигурация Lavalink.

> Это не копия исходного кода. Здесь фиксируются названия/назначение обнаруженных поверхностей и идеи для самостоятельной реализации.
