# CorwinDev — Batch 11

Диапазон: **COR-347–COR-354**

Источник: `CorwinDev/Discord-Bot`, `src/packages`.

## Giveaways package

### COR-347 — Bonus entries для giveaway
Участнику можно выдавать дополнительные шансы на победу через набор `bonusEntries`. Каждое правило может вернуть количество дополнительных entries; поддерживается как выбор максимального бонуса, так и суммирование cumulative-бонусов.

### COR-348 — Исключение победителей по Discord permissions
Giveaway может запрещать победу участникам, имеющим определённые Discord permissions. Проверка выполняется непосредственно при выборе валидных победителей.

### COR-349 — Кастомный фильтр участников giveaway
Giveaway может принимать пользовательскую функцию-фильтр `exemptMembers(member, giveaway)`, позволяющую динамически исключать участников по произвольным условиям (например, роли/статус).

### COR-350 — Настройка участия ботов в giveaway
Можно отдельно разрешить или запретить bot accounts среди участников/победителей. Значение может задаваться для конкретного giveaway или глобально как default.

### COR-351 — Автоматическое удаление завершённых giveaway из БД
Менеджер может хранить завершённые giveaway только заданное время (`endedGiveawaysLifetime`), после чего удалять их из базы. После удаления reroll становится невозможен.

### COR-352 — Принудительное периодическое обновление giveaway
Менеджер может обновлять сообщение giveaway через заданный интервал (`forceUpdateEvery`), даже если содержимое Embed формально не изменилось.

### COR-353 — Проверка изменения Embed перед обновлением giveaway
Перед редактированием сообщения менеджер сравнивает текущий Embed с сгенерированным и обновляет его только при обнаружении изменений; отдельный `forceUpdateEvery` может принудительно обходить эту оптимизацию.

## Weather package

### COR-354 — Выбор языка и единиц измерения в weather lookup
Weather utility принимает язык (`lang`) и тип градусов (`degreeType`) как параметры запроса, поэтому результат можно получать локализованным и в нужной системе температурных единиц.

## Примечание

Полностью просмотрены оба пакета из `src/packages`: `discord-giveaways` и `weather-js`, включая основные исходники, Constants, typings и utility-файл giveaway-пакета. Уже известные giveaway lifecycle-механики (last chance, pause/unpause, drop, edit, reroll, delete) и базовая weather card не дублировались.
