# TitanBot — Fun

Источник: `codebymitch/TitanBot`

## Counting Game

- **TF-001 — Серверная игра счёта как отдельная подсистема** — состояние игры хранится отдельно на каждый guild.
- **TF-002 — Настройка канала игры** — администратор явно выбирает text channel.
- **TF-003 — Несколько систем счёта** — decimal, hexadecimal, binary, base36, base64, roman, math и alphabet.
- **TF-004 — Система счёта с преобразованием значения** — игра сравнивает сообщение с представлением ожидаемого числа, а не только с одной строкой.
- **TF-005 — Math-режим принимает выражение** — игрок может отправить выражение, вычисляемое в следующее число.
- **TF-006 — Math-режим принимает равенство** — допустимо выражение вида `4*4=16`, если обе стороны равны.
- **TF-007 — Нормализация регистра для Roman/Alphabet** — регистр сообщения не влияет на корректность.
- **TF-008 — Строгий формат для обычных систем** — decimal/binary/base36/base64 сравниваются с ожидаемым представлением.
- **TF-009 — Очередность участников** — нельзя засчитывать два последовательных числа от одного пользователя.
- **TF-010 — Текущий streak** — игра хранит длину текущей непрерывной серии правильных ответов.
- **TF-011 — Best streak** — отдельно сохраняется рекорд серии.
- **TF-012 — Личный leaderboard счётов** — каждому пользователю начисляется количество правильных чисел.
- **TF-013 — Топ-10 counting leaderboard** — лидерборд ограничивается десятью позициями.
- **TF-014 — Последний участник** — состояние хранит ID пользователя, который сделал последний правильный ход.
- **TF-015 — Просмотр статуса игры** — показывает enabled, channel, system, next count, streaks и last counter.
- **TF-016 — Безопасный reset с произвольным стартом** — администратор может сбросить последовательность не только к 1, но и к заданному положительному числу.
- **TF-017 — Reset сбрасывает текущую серию и последнего игрока** — рекорд best streak при этом сохраняется.
- **TF-018 — Disable без удаления статистики** — отключение меняет enabled, не уничтожая накопленное состояние.
- **TF-019 — Запрет смены активного канала без disable** — если игра уже активна в другом канале, setup блокируется.
- **TF-020 — Нормализация повреждённого состояния игры** — неизвестная система заменяется на decimal, leaderboard восстанавливается как объект.
- **TF-021 — Fallback при ошибке загрузки состояния** — при проблеме БД игра возвращается к безопасному default state и пишет ошибку.
- **TF-022 — Расширяемый реестр counting systems** — каждая система описывается label/description/toString/parse, поэтому новые основания можно добавлять независимо.
- **TF-023 — Информативные slash choices** — доступные counting systems публикуются как Discord choices.
- **TF-024 — Локальный persisted state по guild ID** — ключ состояния имеет namespace `countingGame:<guildId>`.
- **TF-025 — Игра как административный multi-action command** — setup/disable/status/reset/leaderboard объединены одним slash command.

## Duel / random fun

- **TF-026 — Симулированная текстовая дуэль 1v1** — fight генерирует бой двух реальных пользователей без сложной боевой системы.
- **TF-027 — Случайный победитель дуэли** — исход определяется случайно до генерации раундов.
- **TF-028 — Переменное число раундов** — бой получает случайную длину в заданном диапазоне.
- **TF-029 — Случайный атакующий каждый раунд** — инициатор действия определяется независимо для каждого раунда.
- **TF-030 — Набор случайных боевых действий** — текст раунда выбирается из предопределённого списка действий.
- **TF-031 — Случайный урон внутри раунда** — фактический damage берётся из диапазона, зависящего от общего damage cap.
- **TF-032 — Ограничение длины результата fun-команды** — длинный battle log обрезается под лимит Discord embed description.
- **TF-033 — Самобой блокируется** — пользователь не может вызвать fight против себя.
- **TF-034 — Боты не являются допустимыми соперниками** — duel разрешён только между людьми.
- **TF-035 — Coin flip** — простая heads/tails механика с визуальным результатом в embed.
- **TF-036 — Dice notation** — roll поддерживает стандартную запись `NdS`.
- **TF-037 — Dice modifier** — к сумме броска можно добавить или вычесть фиксированный модификатор.
- **TF-038 — Ограничение количества кубиков** — одна команда может бросить не более 20 кубиков.
- **TF-039 — Ограничение числа граней** — размер кубика ограничен 1000 гранями.
- **TF-040 — Показ отдельных бросков** — при нескольких кубиках пользователь видит каждый результат и итоговую сумму.
- **TF-041 — Нормализация dice notation** — пробелы удаляются, запись приводится к lowercase перед разбором.
- **TF-042 — Строгий parser dice notation** — поддерживается только формат с одним типом кубика и необязательным +/- модификатором.
- **TF-043 — Максимальная длина пользовательского dice input** — notation ограничен 50 символами ещё на уровне Discord option.
