## `commands/🏫 School Commands`

### TOM-073 — Математический калькулятор по выражению
- `calc` принимает математическое выражение из аргументов и вычисляет его через `math-expression-evaluator`.
- Ошибка вычисления обрабатывается отдельно.
- Результат и исходное выражение выводятся в embed.

### TOM-074 — Интерактивный калькулятор с UI
- `calculator` использует готовый интерактивный calculator-компонент `@m3rcena/weky`.
- Пользователь взаимодействует с калькулятором вместо передачи выражения одной строкой.
- Есть отдельные тексты для disabled/invalid query.

### TOM-075 — Вывод длинного значения числа e
- Отдельная команда `e` выводит большое количество знаков числа Эйлера.
- Значение хранится непосредственно в команде и форматируется в embed.

### TOM-076 — Вывод длинного значения числа π
- Отдельная команда `pi` выводит большое количество знаков числа π.
- Значение хранится непосредственно в команде и форматируется в embed.

### TOM-077 — Пользовательские отложенные напоминания
- `remind` принимает длительность и текст через формат `TIME ++ TEXT`.
- Можно складывать несколько временных компонентов (`1h 30m` и т. п.).
- Напоминание сохраняется с timestamp, каналом, сервером, пользователем и текстом.
- Есть ограничение максимальной задержки и защита от нулевой/некорректной длительности.
- В ответе показывается человекочитаемая длительность.

## Примечания по дубликатам
- `calc.js` и `calculator.js` не объединены полностью: обе решают задачу вычислений, но первая — текстовый ввод выражения, вторая — интерактивный UI-калькулятор.
