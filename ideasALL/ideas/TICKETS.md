# Тикеты

Все найденные механики записываются без предварительного отбора.

## CorwinDev/Discord-Bot

### TICKET-001 — Ticket Panel
- Источник: CorwinDev/Discord-Bot
- Категория: Tickets / Community
- Описание: Панель, через которую пользователь создаёт тикет кнопкой.
- Механики / детали: Настройка создаёт отдельное сообщение с заголовком/описанием и компонентом для открытия тикета. В autosetup-варианте используется сообщение `Tickets` с приглашением нажать 🎫. Отдельная команда setup позволяет настраивать ticket panel.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TICKET-002 — Один активный тикет на пользователя
- Источник: CorwinDev/Discord-Bot
- Категория: Tickets / Ограничения
- Описание: Пользователь не может создавать новый тикет, пока предыдущий уже открыт.
- Механики / детали: При попытке повторного открытия система проверяет существующий тикет и возвращает ошибку `Ticket is already open!`. Это предотвращает создание нескольких параллельных обращений одним человеком.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TICKET-003 — Ticket Claim / Unclaim
- Источник: CorwinDev/Discord-Bot
- Категория: Tickets / Staff workflow
- Описание: Сотрудник может взять тикет в работу, а затем снять с себя назначение.
- Механики / детали: В slash-команде есть отдельные `claim` и `unclaim`. Система хранит состояние назначения и отдельно сообщает, если тикет уже не назначен или операция невозможна. Claim превращает общий открытый тикет в обращение, за которое отвечает конкретный сотрудник.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TICKET-004 — Ticket Priority
- Источник: CorwinDev/Discord-Bot
- Категория: Tickets / Staff workflow
- Описание: Тикету можно повышать и понижать приоритет.
- Механики / детали: В проекте присутствуют отдельные операции `raise` и `lower`. Изменение приоритета сопровождается сообщением о том, что ticket был повышен/понижен. Это позволяет сотрудникам визуально или логически выделять более срочные обращения.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### TICKET-005 — Закрытие тикета
- Источник: CorwinDev/Discord-Bot
- Категория: Tickets / Workflow
- Описание: Открытый тикет переводится в закрытое состояние.
- Механики / детали: Есть отдельная команда `close`; при попытке закрыть уже закрытый тикет система сообщает об этом. Закрытие является состоянием тикета, а не только мгновенным удалением канала, поэтому существуют дополнительные операции над закрытым тикетом.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

- Источник: CorwinDev/Discord-Bot

### TICKET-010 — Notification пользователя
- Источник: CorwinDev/Discord-Bot
- Категория: Tickets / UX / Automation
- Описание: Система может отдельно уведомлять автора тикета о необходимости ответа.
- Механики / детали: В стандартном сообщении тикета предусмотрено действие уведомления. Найденная команда `notice` формирует сообщение автору с напоминанием, что при отсутствии ответа в течение 24 часов тикет будет закрыт. Это добавляет автоматизированный follow-up workflow поверх обычного тикета.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО
