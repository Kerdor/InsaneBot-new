# CorwinDev — Batch 6

Диапазон: **COR-294–COR-314**

Начало полного обхода `src/handlers` после закрытия `src/events`.

## Functions / общие обработчики

### COR-294 — Централизованная проверка permissions пользователя и бота
Отдельные helper-функции проверяют права пользователя, права бота или оба набора прав перед выполнением команды.

### COR-295 — Преобразование permission bitfield в названия
Bitfield Discord permissions преобразуется в список человекочитаемых permission names для сообщений об ошибках.

### COR-296 — Унифицированный поиск канала
Канал можно получить по упоминанию, ID или имени.

### COR-297 — Защита текста от mentions
Вспомогательная функция экранирует `@` zero-width символом, предотвращая нежелательные упоминания.

### COR-298 — Beta-версия subcommand через конфигурацию guild
При включённом Beta для guild автоматически загружается `*-beta` реализация subcommand; при проблеме используется обычная версия.

### COR-299 — Проверка temporary voice channel через БД
Отдельный helper определяет, является ли voice-канал зарегистрированным временным каналом.

### COR-300 — Пагинация leaderboard кнопками
Большой leaderboard выводится страницами по 10 элементов с кнопками назад/вперёд.

### COR-301 — Ограничение управления leaderboard по автору
Кнопки пагинации leaderboard обрабатываются только для пользователя, создавшего исходное взаимодействие, и конкретного сообщения.

### COR-302 — Автоотключение leaderboard-кнопок по таймауту
После завершения collector кнопки пагинации становятся disabled.

### COR-303 — Генерация Discord Activity invite
Бот через Discord API создаёт временный invite с `target_application_id`, позволяющий запустить Discord Activity из кнопки.

## Components

### COR-304 — Генератор reaction-кнопок
Набор emoji автоматически превращается в Discord buttons с единым custom ID-префиксом.

### COR-305 — Автоматическое распределение кнопок по ActionRow
Reaction-кнопки автоматически группируются максимум по 5 в строке, вплоть до 5 строк.

### COR-306 — Генератор многоуровневых select menus
Список до 125 options автоматически разбивается на несколько StringSelectMenu по 25 options с различающимися custom ID.

### COR-307 — Унифицированный placeholder select menu
Сгенерированные select menus используют единый placeholder для состояния без выбора.

## Embed / messaging

### COR-308 — Единый template Embed
Общий embed-шаблон автоматически получает имя/аватар бота, цвет из конфигурации, footer и timestamp.

### COR-309 — Централизованные типы ошибок
Отдельные helpers оформляют обычные ошибки, неверные аргументы, отсутствие прав пользователя, отсутствие прав бота и cooldown/wait ошибки в едином стиле.

### COR-310 — Централизованный success response
Успешные операции имеют единый helper с описанием, дополнительными fields и единым success color.

### COR-311 — Унифицированный отправщик interaction responses
Один helper выбирает `edit`, `editReply`, `reply`, `update`, ephemeral-ответ или обычную отправку по параметру `type`.

### COR-312 — Серверный цвет Embed из настроек
Embed автоматически использует индивидуальный цвет guild, если он настроен, иначе применяется глобальный цвет бота.

### COR-313 — Ограничение Embed description
Описание Embed автоматически обрезается до допустимой Discord длины с добавлением `...`.

## Security

### COR-314 — Anti-link / Anti-invite работает и на редактирование сообщений
Защита от ссылок и Discord invites проверяет не только новые сообщения, но и изменённый текст; исключения предусмотрены для DM, модераторов и настроенных исключений каналов.

## Примечание

В этом батче зафиксированы только фактически просмотренные handler-механики. Полный `src/handlers` ещё **не закрыт**: остаются `audio`, `games`, `helppanel`, `linkspanel`, `loaders`, остальные файлы `functions` и детальная проверка security.
