# CorwinDev — Batch 5

Диапазон: **COR-249–COR-285**

Продолжение полного обхода `src/events` после `CORWIN_BATCH4.md`.

## Invite

### COR-249 — Лог создания приглашения
Логирование создания Discord invite в канал логов с кодом приглашения, пригласившим пользователем и относительным timestamp.

### COR-250 — Лог удаления приглашения
Логирование удаления invite с кодом и timestamp.

### COR-251 — Invite tracking при входе
При входе участника определяется приглашение/пригласивший, после чего сохраняется связь `member → inviter`.

### COR-252 — Счётчики приглашений
Для пригласившего ведутся текущие приглашения (`Invites`), общее количество приглашённых (`Total`) и ушедшие (`Left`).

### COR-253 — Invite-aware welcome
Welcome-сообщение поддерживает плейсхолдеры пользователя, пригласившего и количества приглашений.

### COR-254 — Fallback для неизвестного источника входа
Если invite или inviter определить невозможно, welcome отправляется с указанием `System` вместо пригласившего и отдельным текстом о невозможности отследить источник.

### COR-255 — Награды за число приглашений
При достижении заданного количества приглашений пользователю автоматически выдаётся настроенная роль.

## Message events

### COR-256 — Лог удаления сообщений
При удалении сообщения в audit-log записываются автор, дата, канал, содержимое/URL вложения и timestamp. Ботов игнорирует.

### COR-257 — Сохранение вложения в delete-log
Если удалённое сообщение содержит attachment, в лог вместо текста может попасть URL первого вложения.

### COR-258 — Лог редактирования сообщений
Изменение текстового сообщения логируется с автором, каналом, старым и новым содержимым и кнопкой перехода к сообщению.

### COR-259 — Jump-кнопка в edit-log
Для лога редактирования используется link button `Jump to the Message`, ведущая непосредственно на изменённое сообщение.

### COR-260 — Starboard по ⭐
Добавление ⭐ к сообщению создаёт или обновляет запись сообщения в starboard-канале.

### COR-261 — Обновление существующей записи starboard
При изменении количества ⭐ существующий starboard-пост редактируется, а не создаётся заново.

### COR-262 — Удаление starboard при снятии всех ⭐
Если количество звёзд падает до нуля, соответствующая запись starboard удаляется.

### COR-263 — Запрет self-star
Автор сообщения не может поставить ⭐ своему собственному сообщению; бот сообщает об этом пользователю.

### COR-264 — Запрет starboard для bot-сообщений
Сообщения ботов не могут попадать в starboard.

### COR-265 — Starboard только для настроенного сервера
Starboard работает только если для guild настроен канал starboard.

### COR-266 — Starboard не принимает пустые сообщения
Сообщение без текста и поддерживаемого изображения нельзя добавить в starboard.

### COR-267 — Изображение в starboard только поддерживаемых форматов
Для attachment проверяются расширения `jpg/jpeg/png/gif`; неподдерживаемые файлы не используются как изображение starboard.

### COR-268 — Partial recovery для reactions
Перед обработкой starboard reaction/reaction.message при необходимости fetch-ятся из partial-состояния.

## Stats / server statistics

### COR-269 — Счётчик каналов
Отдельный статистический канал автоматически переименовывается с текущим количеством каналов сервера.

### COR-270 — Счётчик текстовых каналов
Статистика может отдельно отображать количество text-каналов.

### COR-271 — Счётчик voice-каналов
Статистика может отдельно отображать количество voice-каналов.

### COR-272 — Счётчик stage-каналов
Статистика может отдельно отображать количество stage-каналов.

### COR-273 — Счётчик forum/news-каналов
Статистика предусматривает отдельный счётчик соответствующих специальных каналов.

### COR-274 — Счётчик ролей
Статистический канал отображает текущее количество ролей.

### COR-275 — Счётчик участников
Статистический канал отображает количество участников сервера.

### COR-276 — Счётчик ботов
Статистический канал отображает количество bot-аккаунтов среди участников.

### COR-277 — Счётчик обычных эмодзи
Отдельный статистический канал показывает количество статических emoji.

### COR-278 — Счётчик анимированных эмодзи
Отдельный статистический канал показывает количество animated emoji.

### COR-279 — Счётчик бустов
Статистика может отображать текущее количество server boosts.

### COR-280 — Уровень бустов сервера
Статистический канал показывает текущий Discord boost tier, преобразуя `NONE/TIER_1/TIER_2/TIER_3` в числовое представление.

### COR-281 — Часы сервера по timezone
Статистический канал с часами регулярно обновляется и показывает локальное время сервера в заданной timezone.

### COR-282 — Единый template для статистических каналов
Название статистического канала формируется через серверный template с плейсхолдерами emoji/name.

## Sticker

### COR-283 — Audit-log sticker lifecycle
Создание, удаление и изменение stickers логируются отдельными событиями; при изменении фиксируются значения `Before/After` и ID.

## Thread

### COR-284 — Audit-log thread lifecycle
Создание, удаление и изменение threads логируются отдельно; update-лог содержит старое/новое имя, ID, parent/category и тип thread.

### COR-285 — Человекочитаемые типы thread
Типы `News Thread`, `Public Thread`, `Private Thread` преобразуются в понятные названия при логировании.

## Warn

### COR-286 — Audit-log добавления предупреждения
При выдаче warn в канал логов записываются пользователь, tag, ID, модератор и причина.

### COR-287 — Audit-log снятия предупреждения
Снятие warn также оформляется отдельным событием/логом с данными пользователя и модератора.

## Voice

### COR-288 — Temporary voice channels
При входе пользователя в настроенный voice-hub бот создаёт ему отдельный временный голосовой канал в заданной категории и перемещает туда пользователя.

### COR-289 — Автоудаление пустых temporary voice channels
Созданный временный voice-канал удаляется, когда в нём больше никого не остаётся; запись канала также удаляется из БД.

### COR-290 — Счётчик temporary voice channels
Количество активных временных голосовых каналов хранится в настройках и корректируется при создании/удалении.

### COR-291 — Шаблон имени temporary voice channel
Название временного voice-канала строится из template с плейсхолдерами emoji, номера канала, количества каналов, username и tag пользователя.

### COR-292 — Игнорирование нерелевантных voice state updates
Обработчик не выполняет основную логику при изменениях mute/deaf/video/streaming, если пользователь остаётся в том же канале.

### COR-293 — Обработка ошибок voice-событий
Для voice-ошибок предусмотрен отдельный event handler.
