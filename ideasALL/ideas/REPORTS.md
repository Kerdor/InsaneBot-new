# REPORTS — Банк идей

Отдельная система пользовательских обращений и связи с персоналом.

## Cog-Creators/Red-DiscordBot

### REPORT-001 — Встроенная система пользовательских reports
- Источник: Cog-Creators/Red-DiscordBot
- Пользователь может отправить жалобу/обращение персоналу без создания обычного ticket channel.
- Report имеет собственный номер и хранится отдельно от тикет-каналов.
- Можно отправить report сразу текстом или пройти интерактивный сценарий через DM.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### REPORT-002 — Выбор сервера для report через DM
- Источник: Cog-Creators/Red-DiscordBot
- Если обращение создаётся вне сервера, бот ищет общие серверы пользователя и бота.
- При нескольких подходящих серверах показывается нумерованный список.
- Пользователь выбирает нужный сервер ответом в DM.
- Отбор может учитывать наличие модератора или требуемые permissions.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### REPORT-003 — Многоуровневый антиспам reports
- Источник: Cog-Creators/Red-DiscordBot
- Для reports одновременно проверяются несколько временных окон: короткое, несколько минут, час и сутки.
- Для каждого окна задаётся собственный лимит.
- Нельзя открыть новый интерактивный report, пока предыдущий ещё находится в процессе.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### REPORT-004 — Вложения в report
- Источник: Cog-Creators/Red-DiscordBot
- При создании обращения бот переносит вложения пользователя вместе с текстом.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### REPORT-005 — DM communication tunnel staff ↔ автор report
- Источник: Cog-Creators/Red-DiscordBot
- Сотрудник может открыть отдельный канал связи с автором обращения.
- Сообщения из staff-канала пересылаются пользователю в DM, а ответы пользователя возвращаются персоналу.
- Поддерживаются файлы/вложения.
- В интерфейсе отображается состояние открытой переписки.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### REPORT-006 — Закрытие communication tunnel реакцией
- Источник: Cog-Creators/Red-DiscordBot
- Открытую переписку можно завершить реакцией ❎ на последнее сообщение.
- Закрыть tunnel могут участники этой коммуникации.
- Наш вариант: ⬜
- Статус: ⬜ НЕ РЕШЕНО

### REPORT-007 — Постоянная последовательная нумерация обращений
- Источник: Cog-Creators/Red-DiscordBot

- Каждый новый report получает последовательный номер, пригодный для аудита и идентификации.
