# PYTHON-DISCORD — Дополнительные идеи

Отдельный тематический файл для механик `python-discord/bot`, которые не стоит смешивать с уже существующими общими категориями до завершения полного обхода источника.

## PDIS-001 — Постоянная self-role панель с восстановлением после рестарта
- Источник: `python-discord/bot`
- В серверном канале хранится одно постоянное сообщение с кнопкой открытия панели self-roles.
- При старте cog бот ищет существующее сообщение по содержимому и повторно подключает persistent view по `message_id`.
- Если сообщение отсутствует, бот создаёт его заново.
- Это отдельный механизм восстановления UI после перезапуска, а не просто button roles.
- Временная пользовательская панель после вызова имеет timeout и автоматически удаляется.

## PDIS-002 — Персональная интерактивная role-панель
- Источник: `python-discord/bot`
- Каждая кнопка показывает текущее состояние роли конкретного пользователя: Add/Remove.
- После нажатия стиль и текст самой кнопки меняются на противоположное состояние.
- Панель может работать ephemeral, поэтому управление ролями не засоряет канал.
- Взаимодействие разрешено только пользователю, вызвавшему команду; чужой клик получает ephemeral-ошибку.
- После успешного изменения роли пользователь получает отдельное ephemeral-подтверждение.
- Список ролей перед отображением сортируется по имени.

## PDIS-003 — Временная выдача отдельного permission-role
- Источник: `python-discord/bot`
- Модератор может выдать пользователю специальную роль доступа на заданный срок.
- Срок хранится отдельно и после истечения роль автоматически снимается.
- Фоновый scheduler восстанавливает незавершённые снятия после рестарта из persistent cache.
- Если пользователь покинул сервер до окончания срока, устаревшая задача очищается.

## PDIS-004 — Upgrade временного доступа до постоянного
- Источник: `python-discord/bot`
- Если у пользователя уже есть временный permission-role, отдельная команда может отменить scheduled revoke и превратить доступ в постоянный.
- Это отдельный workflow перехода состояния, а не повторная выдача роли.

## PDIS-005 — Список временных и постоянных доступов с сортировкой по истечению
- Источник: `python-discord/bot`
- Команда списка показывает пользователей с permission-role и различает временный и постоянный доступ.
- Временные записи сортируются по ближайшему времени снятия, постоянные помещаются в конец.
- Длинный список выводится через paginator.

## PDIS-006 — Принудительное завершение активного stream
- Источник: `python-discord/bot`
- При отзыве streaming-доступа бот дополнительно проверяет, ведёт ли пользователь стрим прямо сейчас.
- Если да, пользователя временно перемещают в AFK voice и возвращают обратно, чтобы принудительно синхронизировать состояние.

## PDIS-007 — Silence канала с сохранением исходных overwrites
- Источник: `python-discord/bot`
- При временной блокировке канала бот сохраняет предыдущие permission overwrites для последующего точного восстановления.
- Для text channel сохраняются права отправки сообщений, реакций и создания/отправки сообщений в threads.
- Для voice channel отдельно учитываются Speak и при необходимости Connect.
- Если предыдущие overwrite потеряны, есть fallback-восстановление значениями `None`, плюс отдельное уведомление о ручном вмешательстве.

## PDIS-008 — Silence text и voice channels одной системой
- Источник: `python-discord/bot`
- Одна команда умеет временно или бессрочно блокировать text и voice channels.
- Для voice channel предусмотрены два режима: принудительная синхронизация участников или фактическое исключение участников без возврата.
- Threads нельзя заглушить отдельно: система явно требует работать с родительским каналом.

## PDIS-009 — Бессрочный silence с периодическими напоминаниями staff
- Источник: `python-discord/bot`
- Каналы, заглушённые навсегда, попадают в отдельный notifier.
- Пока список не пуст, notifier работает; когда каналов не осталось, цикл останавливается.
- Для бессрочно заглушенных каналов staff получает периодическое напоминание с перечнем каналов и длительностью silence.

## PDIS-010 — Защита от гонок операций над одним ресурсом
- Источник: `python-discord/bot`
- Для операций silence/unsilence используется именованный lock на конкретный канал.
- Параллельные команды для одного ресурса не должны одновременно менять permission state.

## PDIS-011 — Условный redirect вывода команды
- Источник: `python-discord/bot`
- Результат команды можно централизованно перенаправлять в специальный bot-commands channel.
- Redirect можно обходить для определённых ролей, каналов или категорий.
- Пользователь получает ссылку/указатель на новое место вывода.
- При необходимости исходный command message и redirect notice автоматически удаляются.
- Исходную команду можно перед удалением сохранить во внешнем paste-service; пользователю выдаётся DM со ссылкой на удаление сохранённой копии.
- Основная команда запускается как отдельная background task, поэтому redirect-обвязка не обязана ждать её полного выполнения.

## PDIS-012 — Whitelist/blacklist контекст команды с перенаправлением
- Источник: `python-discord/bot`
- Доступ к команде можно ограничивать одновременно списками каналов, категорий и ролей.
- Для blacklist предусмотрены override-роли.
- При запрете можно либо молча отклонить команду, либо направить пользователя в разрешённый канал.

## PDIS-013 — Проверка target role hierarchy как reusable decorator
- Источник: `python-discord/bot`
- Проверка иерархии вынесена в переиспользуемый decorator, принимающий имя/позицию аргумента target member.
- Если target не является guild member, проверка пропускается.
- При равной/высшей роли действие не вызывается, пользователь получает точное объяснение причины.

## PDIS-014 — Проверка доступности внешнего URL до выполнения команды
- Источник: `python-discord/bot`
- URL-конвертер может выполнять HTTP GET заранее и принимать аргумент только при статусе 200.
- Отдельно диагностируются invalid hostname, connection failure и certificate error.

## PDIS-015 — Валидация Discord Snowflake по timestamp
- Источник: `python-discord/bot`
- ID проверяется не только на формат цифр, но и на корректный timestamp Discord epoch.
- Отбрасываются snowflake из невозможного прошлого и слишком далёкого будущего.

## PDIS-016 — Унифицированные duration/age converters
- Источник: `python-discord/bot`
- Один parser поддерживает составные длительности с единицами лет/месяцев/недель/дней/часов/минут/секунд.
- Отдельные converters превращают строку либо в дату окончания, либо в дату начала относительно текущего момента.

## PDIS-017 — Resource topic → нормализованный deep-link
- Источник: `python-discord/bot`
- Текст темы нормализуется в kebab-case и превращается в query-параметр URL.
- Несколько разделителей схлопываются в один `-`, апострофы удаляются, края очищаются.
- Первая строка многострочного аргумента используется как topic.

## PDIS-018 — Интерактивная команда с persistent и ephemeral UI одновременно
- Источник: `python-discord/bot`
- Общая система может иметь постоянную публичную кнопку-панель и создавать по запросу приватную ephemeral-панель с текущим состоянием пользователя.
- Это позволяет держать один стабильный entry point и не хранить отдельную публичную панель на каждого пользователя.
