# CorwinDev — Batch 7

Диапазон: **COR-315–COR-332**

Продолжение полного обхода `src/handlers`.

## Audio

### COR-315 — Музыкальное управление через message buttons
Панель проигрывателя управляется кнопками pause/resume/stop/next/previous с обновлением Embed и состояния кнопок.

### COR-316 — Восстановление radio после перезапуска
При `ClientReady` бот загружает сохранённые radio channels из БД и снова подключается к ним.

### COR-317 — Автовосстановление radio stream после Idle/error
При завершении или ошибке audio player radio автоматически запускает поток заново.

### COR-318 — Stage channel auto-unsuppress
После подключения к Stage Channel бот автоматически снимает suppress со своего voice member.

### COR-319 — Очередь soundboard с последовательным проигрыванием
Звуки складываются в очередь на guild и проигрываются последовательно; после окончания очереди voice connection уничтожается.

## Games / automation

### COR-320 — Counting game с математическими выражениями
В counting channel принимаются не только числа, но и математические выражения, результат которых вычисляется перед проверкой.

### COR-321 — Counting game запрещает два последовательных хода одного пользователя
Если тот же пользователь отправляет следующее число, серия сбрасывается на 1.

### COR-322 — Guess-number с визуальными подсказками реакциями
При неверной попытке бот реагирует стрелкой вверх/вниз, показывая направление к правильному числу.

### COR-323 — Guess-number автоматически создаёт следующую цель после выигрыша
После угадывания генерируется новое число и игра продолжается без отдельного запуска.

### COR-324 — Guess-word с перемешанными буквами
После победы генерируется новое слово, его буквы перемешиваются и публикуются как следующая задача.

### COR-325 — Word-snake по последней букве предыдущего слова
Следующее слово должно начинаться с последней буквы предыдущего; корректные и ошибочные ответы отмечаются реакциями.

### COR-326 — Унифицированные XP helpers с пересчётом уровня
Изменение XP автоматически пересчитывает level по формуле; отдельные helpers позволяют устанавливать/добавлять XP или level.

### COR-327 — Получение позиции пользователя в XP leaderboard
При запросе level-data helper может дополнительно вычислить место пользователя среди всех участников guild.

## Help / links UI

### COR-328 — Help panel с категориями команд в select menu
Help-панель содержит список категорий команд и переключает содержимое существующего сообщения без отправки нового сообщения.

### COR-329 — Help panel с кнопочной пагинацией
Большой список команд разделён на страницы и переключается кнопками Previous/Next, доступными только пользователю, открывшему панель; collector имеет таймаут.

### COR-330 — Единая навигационная панель ссылок
Отдельные страницы Bot Invite, Support Server, Community Server и Top.gg используют общий select menu и переходят друг в друга редактированием исходного сообщения.

### COR-331 — Link buttons для внешних ресурсов
Страницы help/links panel используют Discord link buttons для приглашения бота, support/community server и голосования на Top.gg.

## Loaders / architecture

### COR-332 — Динамическая регистрация событий по структуре директорий
Event loader автоматически обходит подкаталоги `src/events`, подключает `.js` файлы и использует `Discord.Events` при наличии стандартного имени события, иначе регистрирует кастомное событие по имени файла.

## Примечание

Фактически просмотрены `audio`, `games`, `helppanel`, `linkspanel`, `loaders` и дополнительные файлы `functions`. `src/handlers` ещё **не закрыт**: требуется финальная проверка оставшихся handler-файлов/веток и сверка перед переходом к `src/interactions`.
