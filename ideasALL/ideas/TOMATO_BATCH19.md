# Tomato6966 — Batch 19
Источник: `Tomato6966/Multipurpose-discord-bot`
Ветка: `new_2025`
Область: `slashCommands/`

## TOM-248 — Повтор текущего трека с начала
Музыкальная команда `replay` перематывает текущий трек на позицию `0`, не создавая новый трек и не меняя очередь. Работает только при активном player и с DJ-проверкой.

## TOM-249 — Статистика действий модератора по пользователю
Команда `modstats` показывает накопленную статистику выбранного модератора/администратора: баны, кики, муты, тикеты, отправленные через модерацию сообщения, предупреждения и дополнительные счётчики из профиля статистики. Данные хранятся отдельно для пары `guild + user`.

## TOM-250 — Диагностика размера исходного кода бота
Команда `commandcount` показывает количество загруженных команд и категорий, а также вычисляет объём проекта обходом файловой системы: количество строк и символов исходных файлов. В расчёт не включается `node_modules`; результат выводится как диагностическая карточка.

## TOM-251 — Расширенная карточка статистики приглашений
Карточка приглашений пользователя показывает не только общее число приглашений, но и разделяет `joins`, `fake`, `leaves` и вычисляет `real invites = joins - fake - leaves`. Дополнительно выводится счётчик сообщений пользователя; данные привязаны к `guild + user` и сохраняют списки приглашённых/ушедших участников и информацию об использованном invite.

## TOM-252 — Интерактивный FAQ через Select Menu
FAQ бота оформлен как интерактивное меню выбора: первоначальное ephemeral-сообщение содержит список вопросов, а выбор пункта отправляет соответствующий ответ отдельным ephemeral Embed. Ответы могут динамически подставлять данные бота: число команд, серверов, uptime, ping, prefix, число партнёров и т.п.

## TOM-253 — SoundCloud: поиск + мгновенный skip текущего трека
Отдельная музыкальная команда позволяет одновременно найти/указать трек SoundCloud и сразу заменить текущий трек, передавая запрос в music player manager с режимом `skiptrack:soundcloud`. Это отдельная комбинация обычного play и skip.

## TOM-254 — Набор генераторов мемов/изображений через API
В `slashCommands/Fun` есть отдельный слой image/meme-команд поверх `memer-api`: генерация изображения по тексту или аватару пользователя. Набор включает готовые визуальные эффекты/мем-шаблоны вроде `stonks`, `notstonks`, `wanted`, `wasted`, `rip`, `rainbow`, `sepia`, `stroke`, `trash`, `ohno`, `shit`, `whodidthis`, `roblox`, `note` и др. Общий UX: параметр/пользователь → API-генерация → вложение PNG в Embed; часть команд использует аватар выбранного пользователя.

## Проверено и не добавлено
- `slashCommands/Admin/embed.js` и `say.js` — варианты уже существующих send/embed administration-механик, без достаточной новой самостоятельной системы.
- `slashCommands/Info/help.js`, `permissions.js`, `userinfo.js`, `serverinfo.js`, `ping.js`, `uptime.js`, `avatar.js`, `roleinfo.js`, `serveravatar.js`, `color.js`, `emojiinfo.js`, `botinfo.js`, `developer.js`, `stats.js` — информационные команды/варианты уже покрытых базовых Info-механик или их slash-интерфейс.
- `slashCommands/Info/translate.js` — текущая реализация использует `args`, которые в данном slash-командном файле не определены; рабочей механикой не считается.
- Большинство `slashCommands/Music/*` — slash-варианты уже исследованных музыкальных действий: play, queue, skip, playtop, shuffle/unshuffle, now playing, seek, forward/rewind, volume, loop, autoplay, music mix и т.п.
- `slashCommands/Fun/*` с простыми API-мемами свернуты в одну общую систему TOM-254, а не размножены по отдельной идее на каждый шаблон.
- `slashCommands/NSFW/*` — набор NSFW API-команд/вариантов выдачи контента; новых общих архитектурных механик относительно уже исследованных систем не выявлено.
