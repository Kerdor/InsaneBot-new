# CorwinDev — Batch 8

Диапазон: **COR-333–COR-341**

Продолжение полного обхода `src/interactions`.

## Interaction architecture

### COR-333 — Единый subcommand dispatcher для категорий
Составные slash-команды с категориями и подкомандами используют общий `loadSubcommands` dispatcher: корневая команда отвечает только за описание структуры, а выполнение передаётся соответствующему обработчику.

### COR-334 — Категории команд с встроенным `help` subcommand
Большинство функциональных категорий имеют отдельную `/category help` подкоманду прямо внутри той же slash-команды для навигации по возможностям категории.

### COR-335 — Отложенный ответ перед длительной обработкой interaction
Корневые slash-команды передают выполнение подкомандам после `deferReply`, что позволяет безопасно обрабатывать операции, требующие дополнительного времени.

## Discord Activities

### COR-336 — Запуск Discord Activities через slash-команду
Команда `/activities` предлагает список Discord Activities через choices и запускает выбранную Activity в voice channel пользователя через Activity invite API.

### COR-337 — Проверка нахождения пользователя в voice channel перед Activity
Перед созданием Activity invite бот проверяет, находится ли инициатор команды в голосовом канале, и возвращает ошибку при отсутствии voice channel.

## Interactive UI

### COR-338 — Интерактивный конструктор Embed через select menu
Команда создания Embed использует select menu для пошагового выбора редактируемых частей (title, description, author, footer, thumbnail, timestamp, image, URL, color) и обновляет один существующий Embed.

### COR-339 — Ввод данных для UI через временный message collector
Для выбранного поля интерактивного конструктора бот отправляет запрос в канал, ожидает одно сообщение только от инициатора с таймаутом, затем удаляет запрос и введённое значение.

### COR-340 — Отправка пользовательского Embed через временный webhook
После завершения интерактивного конструктора бот создаёт webhook с именем/аватаром guild, отправляет через него готовый Embed, затем через несколько секунд удаляет webhook и служебное сообщение.

## Context menus

### COR-341 — User context menu для модерации с последующим interaction flow
Модерационные действия `Warn`, `Unwarn` и `Warnings` доступны как User Context Menu. `Warn` открывает Modal для причины, `Unwarn` показывает select menu со списком Case и позволяет удалить выбранное предупреждение, а `Warnings` выводит все предупреждения выбранного пользователя.

## Примечание

Фактически просмотрены `src/interactions/Command` и `src/interactions/ContextMenu`. Большинство Command-файлов являются декларациями slash-команд и маршрутизацией в уже исследованные реализации `src/commands`; новые уникальные механики зафиксированы выше. `src/interactions` ещё требует финальной сверки полного дерева перед закрытием.
