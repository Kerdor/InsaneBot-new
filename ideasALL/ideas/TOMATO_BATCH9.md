# Tomato6966 — Batch 9

## `commands/💪 Setup` — часть 1

### TOM-107 — Массовое включение/выключение категорий команд
- Setup позволяет выбрать сразу несколько категорий команд через multi-select.
- Для каждой выбранной категории состояние переключается независимо.
- После операции показывается, сколько категорий включено и выключено.
- В текущей реализации категории хранятся отдельными guild-настройками (`ECONOMY`, `MUSIC`, `MINIGAMES` и т. п.).

### TOM-108 — Настраиваемый Number Counter
- Администратор назначает конкретный канал для последовательного счёта чисел.
- Можно полностью отключить систему.
- Текущее число хранится отдельно и может быть сброшено обратно в `0`.
- Setup показывает текущий номер и следующий ожидаемый номер.

### TOM-109 — Ежедневные автоматические факты
- Администратор выбирает канал для ежедневной публикации фактов.
- Систему можно включить/выключить.
- Setup показывает настроенный канал и фиксированный интервал `24 часа`.

### TOM-110 — Защита от слишком новых Discord-аккаунтов
- Сервер может автоматически обнаруживать аккаунты младше заданного возраста.
- Действие настраивается отдельно: `kick` или `ban`.
- Минимальный возраст аккаунта задаётся человеком в естественном формате времени (`2 Days`, `6 hours + 2 Days` и т. п.).
- Можно задать дополнительное сообщение, отправляемое пользователю в DM.
- Есть отдельный экран просмотра всех настроек системы.

### TOM-111 — Настраиваемый Anti-Spam с лимитом сообщений
- Администратор задаёт максимальное количество сообщений за 10 секунд.
- Ограничение в этой реализации: от `1` до `30` сообщений.
- При превышении сообщения пользователя удаляются; дальнейшее нарушение приводит к mute.
- Можно добавлять и удалять каналы из whitelist.
- Отдельно настраивается количество нарушений, после которого применяется mute.
- Есть экран текущих настроек и отдельное включение/выключение.

### TOM-112 — Anti-Link с whitelist каналов и ссылок
- Можно включать/выключать удаление ссылок.
- Отдельно задаётся whitelist каналов, в которых ссылки разрешены.
- Отдельно задаётся whitelist ссылок/доменов; проверка работает по содержанию ссылки, поэтому можно сохранять домен без `https`.
- Whitelist каналов и ссылок можно добавлять и удалять.
- Настраивается максимальное число нарушений за 15 секунд перед mute.
- Есть просмотр текущих настроек.

### TOM-113 — Персональное DM-сообщение при бусте сервера
- Сервер может автоматически отправлять бустеру благодарственное сообщение в DM.
- Сообщение задаётся администратором как произвольный текст.
- Систему можно отключить.

### TOM-114 — Отдельный Boost Log с настраиваемыми сообщениями
- Можно указать отдельный канал для логов начала/окончания буста.
- Лог можно включать и отключать независимо от DM-сообщения.
- Отдельно настраиваются три шаблона: первый буст, прекращение буста и повторный буст.
- В шаблонах поддерживается placeholder `{member}`, который заменяется на пользователя.

### TOM-115 — Ghost-Ping Detector с настраиваемым окном обнаружения
- Можно включить отдельный канал для логов ghost ping.
- Настраивается максимальный промежуток между упоминанием и удалением сообщения, в пределах которого оно считается ghost ping.
- В текущей реализации значение передаётся вместе с каналом; при некорректном времени используется fallback `10 секунд`.
- При отключении системы окно обнаружения сбрасывается на `10 секунд`.
- Есть просмотр текущего канала и максимального времени обнаружения.

### TOM-116 — Epic Games Account Verification
- Сервер может создать отдельный канал с интерактивной кнопкой для привязки/верификации Epic Games аккаунта.
- Пользователь может повторно нажать кнопку, чтобы изменить связанные данные.
- Для системы хранится отдельный verification channel.
- Дополнительно можно включить action-log в отдельном канале.
- Лог можно отключить независимо от самой верификации.
